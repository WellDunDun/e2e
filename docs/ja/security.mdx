e2e は、あなたが書いたコードを信頼し、アプリが表示するものはすべて信頼できないものとして扱います。
アプリのコンテンツが、モデルにツール、認証情報、より大きな予算を与えることはできません。

## シークレットをモデルから遠ざける仕組み

`Secret` は、平文を取り出すアクセサーを持たないハンドルです。モデルに見えるのは、その名前と目的だけです。
モデルがシークレットの入力を求めると、ランナーはフィールドを確認し、値を自分で入力します。

既知のシークレットの値はすべて、モデルのテキスト入力、レポート、コンソール出力、そして
`.txt`、`.csv`、`.json`、`.html`、`.htm` のダウンロードで `<secret:name>` に置き換えられます。

## それでも漏れうるもの

秘匿処理は文字列の一致で行われ、スクリーンショットでマスクされるのはセキュアなフィールドだけです。

- **スクリーンショット（モデルに渡すものを含む）。** 通常の入力欄に入力された汎用のシークレットや、
  アプリがセキュアなフィールドの外に表示する値は、画像に含まれ、モデルプロバイダーに送られます。
  本番のシークレットではなく、テスト用の認証情報を使ってください。
- **動画とダウンロード。** 動画では何もマスクされず、秘匿処理されたテキストファイル以外のダウンロードは
  配信されたまま保持されます。テストでパスワードを入力した場合は、共有する前にそれらを確認してください。
- **`command.log`。** アプリの stdout と stderr がそのまま記録されます。アプリの出力に
  シークレットを含めないでください。
- **変換された値。** キーの末尾 4 文字や、その base64 は、そのまま通過します。
  シークレットではなく、結果をアサートしてください。
- **シークレットとして入力されていない値。** 秘匿処理されるのは、設定されたシークレットの値だけです。
  サインインによって Cookie に設定された値は秘匿処理されません。
- **リクエストの認証情報。** `headers` は、アプリのオリジンまたは列挙したオリジンから始まるすべての
  リクエストに付与されます。サードパーティのページが開始したリクエストも対象で、任意のオリジンへの
  リダイレクトでも付与されたままです。`basicAuth` は、それらのオリジンからの `401` に応答します。
  また、それらのいずれかがデフォルトポートを使っているか IPv6 のホストを持つ場合、WebKit では
  任意のオリジンからの `401` に応答します。
- **コミットされた記録。** キャッシュのエントリーには、シークレットの入力を除き、入力した値が
  そのまま保存されます。エントリーは署名されておらず、あなたの権限でリプレイされるため、
  テストコードと同じようにレビューしてください。

[秘匿処理が及ばない範囲](/reference/security#where-redaction-stops) に、すべてのケースが記載されています。

## モデルが見るものと行うこと

モデルに見えるのは、あなたの指示、アクセシビリティツリーとしての画面、秘匿処理された URL、
そしてテスト内の以前のステップの記録です。モデルがスクリーンショットを要求した場合や、
ステップで `vision` が設定されている場合は、マスクされたスクリーンショットを受け取ります。

モデルはツールを通じてのみ操作します。ランナーは、各呼び出しを実行する前に閉じたスキーマに
照らして確認し、モデルのテキストをコードとして評価することは決してありません。`file:` への
ナビゲーションなど、ルールに違反する呼び出しは `POLICY_DENIED` で失敗します。オリジンの許可リストは
ありません。エージェントはアプリに従って別のサイトに移動し、そこでステップのシークレットを使えます。

## あなたの権限で実行されるもの

テスト、設定、エンジン、ツール、レポーター、ストア、シークレットプロバイダー、アプリのコマンドは、
サンドボックス化されずに、あなたのオペレーティングシステムの権限で実行されます。
信頼できないプルリクエストのコードは、シークレットや書き込みトークンのない外部のサンドボックスで実行してください。

## コンピューターの外に送られるもの

実行は、モデルプロバイダー、テスト対象のアプリ、そしてオプトアウトしない限り `eu.i.posthog.com` の
[テレメトリー](/telemetry) に接続します。クラッシュレポートはありません。ターミナル上の CLI コマンドは、
新しいリリースがないか `registry.npmjs.org` を 1 日に最大 1 回確認します。`e2e feedback` は、
`--allow-outdated` を指定しない限り、各レポートの前に確認します。`e2e upgrade` は、プロジェクトに
記載された e2e パッケージのバージョンを読み取ります。Kernel、Expo Simulators、Limrun、smol などの
インテグレーションは独自の接続先を追加します。それらは他の接続先とあわせて
[外向きの接続](/reference/security#outbound-connections) に記載されています。

## 脆弱性を報告する

[GitHub security advisories](https://github.com/e2e-inc/e2e/security/advisories/new) を通じて、
または security@e2e.com へのメールで、非公開で報告してください。
[セキュリティポリシー](https://github.com/e2e-inc/e2e/blob/main/SECURITY.md) に、
応答時間とサポート対象のバージョンが記載されています。
