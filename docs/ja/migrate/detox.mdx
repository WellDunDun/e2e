export const migrationPrompt = `このプロジェクトの Detox テストを、spec 1 つずつ e2e に移行してください。ドキュメント: \`https://e2e.com/docs/migrate/detox.md\` と \`https://e2e.com/docs/mobile.md\`

1. 上記の移行ガイドを読んでください。\`.detoxrc.js\` と Detox API を e2e に対応付けており、e2e にまだないものも一覧にしています。モバイルガイドではデバイスとアプリのビルドを扱っています。
2. プロジェクトに e2e の設定 (\`e2e.config.ts\`、\`.mts\`、\`.js\`、\`.mjs\`) がない場合は、\`npx e2e init --yes --engine mobile\` (または pnpm や bun の同等のコマンド) を実行してください。このマシンのプラットフォーム向けのターゲットを 1 つ持つモバイル設定と、設定アプリを対象にしたサンプルテストを書き出し、まだ何もインストールしません。\`tests/example.e2e.ts\` は自分のアプリ向けに書き直すか、削除してください。
3. e2e のスキルを読み (\`npx e2e guide\` で表示され、\`npx e2e guide <topic>\` でトピックを表示します)、以下のすべてのステップでそれに従ってください。
4. init を実行した場合は、エージェントのステップに使うモデルを私に尋ねてください: ChatGPT、GitHub Copilot、OpenCode Console、SuperGrok のサブスクリプション、API キー、またはローカルモデルです。そのプロバイダーパッケージで設定してください。サインインが必要な場合は、\`npx e2e login\` コマンドを私に伝え、私が確認するまで待ってください。
5. \`.detoxrc.js\` を e2e の設定に移してください: \`mobile({ platform })\` でプラットフォームごとにターゲットを 1 つ作り、アプリの \`bundleId\` と \`appPath\` をターゲットに置き、デバイスの種類は \`mobile({ device })\` にします。e2e は Detox フレームワークを含まない通常の debug または release ビルドを使います。
6. 依存関係をインストールし、\`npx e2e doctor\` (e2e 0.23.0 以降) を実行して、報告された問題を修正してください。
7. Detox の spec を一覧にし、最初にどれを移すか私に尋ねてください。頻繁にメンテナンスが必要なフローを提案してください。
8. その spec の各 Detox 呼び出しを "What e2e doesn't have yet" と照らし合わせてください。"Use today" または "Use instead" の項目を使うか、spec を Detox に残してその理由を述べてください。次に、ガイドの対応表を使って、spec を Detox のフォルダではなく \`tests/\` 配下の \`.e2e.ts\` ファイルとして書き直してください (e2e はデフォルトで \`tests/**/*.e2e.ts\` を実行します)。何も自動では起動しないので、\`app.open()\` から始めてください。複数のノードに一致するクエリは絞り込んでください。
9. 起動と最後のアサーションは、\`app.open()\` とロケーターのアサーションで決定論的に保ってください。スクリプト化した一連の操作が頻繁に壊れる箇所では、代わりに \`agent.act\` のゴールを提案してください。
10. アプリをビルドしてインストールし、各プラットフォームのターゲットで \`npx e2e run <file>\` を使って新しいファイルを実行し、通るまで修正してください。削除してよいと私が確認するまで、Detox の spec は残しておいてください。
11. どのテストを移行し、どのテストを Detox に残したか、その理由とともにまとめてください。`;

e2e は、アプリに Detox フレームワークを入れず、通常の debug または release
ビルドで、シミュレーターやエミュレーター上の React Native アプリをテストします。
`testID` props は両プラットフォームで `getByTestId` で使えます。

複数のセッションにまたがる移行では、[`migrate-to-e2e` スキル](/coding-agents#migrate-an-existing-suite) が移行済みのものを進捗ファイルに記録し、各テストを廃止するまで古いスイートを動かし続けます。

## 設定を移す

<Note>[モバイルガイド](/mobile) でターゲットを、[クイックスタート](/quickstart) でモデルを設定してください。spec を 1 つずつ移す間、両方のランナーが同じシミュレーターを使えます。</Note>

| Detox (`.detoxrc.js`) | e2e |
| --- | --- |
| `apps.<name>.binaryPath`, `bundleId` | ターゲットの `app: { appPath, bundleId }` |
| `devices.<name>.device.type` | `mobile({ device: 'iPhone 17' })` |
| `configurations` | `targets`、プラットフォームごとに 1 つのエンジン |
| Jest `maxWorkers` | `workers`、デバイスごとに 1 つ |
| `apps.<name>.launchArgs` | ターゲットの `app.launchArguments`、プラットフォームごとの文字列のリスト |
| `launchApp({ permissions })` | ターゲットの `app.permissions`: `YES`、`NO`、`unset` に対して `grant`、`deny`、`reset`。その他の名前は[予定されています](#planned) |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';

export default {
  targets: [
    {
      name: 'ios',
      engine: mobile({ platform: 'ios' }),
      app: { bundleId: 'com.example.app', appPath: 'ios/build/MyApp.app' },
    },
    {
      name: 'android',
      engine: mobile({ platform: 'android' }),
      app: { bundleId: 'com.example.app', appPath: 'android/app/build/outputs/apk/debug/app-debug.apk' },
    },
  ],
  workers: 1,
} satisfies E2EConfig;
```

## spec を 1 つ書き直す

何も自動では起動しないので、e2e のテストは `app.open()` から始めます。
パスワードは[設定した認証情報](/authentication)から取得します。

```js title="Detox"
describe('login', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }); });

  it('shows the home screen', async () => {
    await element(by.id('email')).typeText('ada@example.test');
    await element(by.id('password')).typeText('hunter2');
    await element(by.text('Sign in')).tap();
    await waitFor(element(by.id('home'))).toBeVisible().withTimeout(10000);
    await expect(element(by.text('Welcome, Ada'))).toBeVisible();
  });
});
```

```ts title="e2e"
import { test } from '@e2e-dev/mobile';
import { expect, credentials } from 'e2e';

test('shows the home screen', async ({ agent, app, screen }) => {
  await app.open();
  const ada = credentials.user('ada');
  await agent.act('sign in as {username}', { params: { username: ada.username, password: ada.password } });
  await expect(screen.getByTestId('home')).toBeVisible({ timeout: 10_000 });
  await expect(screen.getByText('Welcome, Ada')).toBeVisible();
});
```

## Detox の各呼び出しを対応付ける

### マッチャーとアクション

| Detox | e2e |
| --- | --- |
| `by.id('x')`, `by.text('t')`, `by.label('l')` | `screen.getByTestId('x')`, `screen.getByText('t')`, `screen.getByLabel('l')` |
| `by.id('x').withAncestor(by.id('row'))` | `screen.getByTestId('row').getByTestId('x')` |
| `.atIndex(n)` | `.nth(n)` |
| `.tap()`, `.tap({ x, y })`, `.longPress()`, `.multiTap(2)` | `.tap()`, `.tap({ position: { x, y } })`, `.longPress()`, `.doubleTap()` |
| `.typeText(t)` | `.pressSequentially(t)` |
| `.replaceText(t)`, `.clearText()`, `.tapReturnKey()` | `.fill(t)`, `.clear()`, `.press('Enter')` |
| `.swipe('up', 'fast')` | `.swipe({ direction: 'down', momentum: 'fast' })`。Detox は指の方向を、e2e はコンテンツの方向を指定します |
| `list.scroll(200, 'down')` | `list.swipe({ direction: 'down' })`、オフセットなし |
| `waitFor(el).toBeVisible().whileElement(list).scroll(...)` | `list.scrollUntilVisible(el)`。Detox が上にスクロールする場合は `{ direction: 'up' }` を付けます |

### 期待値

| Detox | e2e |
| --- | --- |
| `waitFor(el).toBeVisible().withTimeout(ms)` | `await expect(el).toBeVisible({ timeout: ms })` |
| `.toBeVisible()`, `.toHaveText(t)` | 同じ |
| `.not.toBeVisible()` | `.toBeHidden()` |
| `.toExist()`, `.not.toExist()` | `.toBeAttached()`, `.toBeAttached({ attached: false })` |
| `.toHaveToggleValue(true)` | `.toBeChecked()` |
| `.toHaveLabel(l)` | `.toHaveAccessibleName(l)` |
| `.toHaveValue(v)` | `.toHaveValue(v)`、フォームコントロールのみ |

### デバイス

| Detox | e2e |
| --- | --- |
| `device.launchApp({ newInstance: true })` | `app.restart()` |
| `device.launchApp({ newInstance: false })` | `relaunch` なしの `device.openApp(id)` |
| `device.launchApp({ launchArgs, permissions })` | `device.openApp(id, { relaunch: true, launchArguments, permissions })` |
| `device.resetAppState()` | `app.clearState()` |
| `device.launchApp({ delete: true })` | `device.installApp(path, { reinstall: true })` の後に `app.open()` |
| `device.launchApp({ url })`, `device.openURL({ url })` | `device.openLink(url)` |
| `device.terminateApp()`, `sendToHome()`, `pressBack()` | `device.closeApp()`, `home()`, `back()` |
| `device.setLocation(lat, lon)`, `setOrientation('landscape')` | `device.setLocation({ latitude, longitude })`, `setOrientation('landscape-left')` |
| `device.setBiometricEnrollment(true)` | `device.enrollBiometrics('faceid', true)` |
| `device.matchFace()`, `unmatchFace()`, `matchFinger()`, `unmatchFinger()` | `device.setBiometrics('faceid' \| 'touchid', 'match' \| 'nonmatch')` |
| `device.takeScreenshot()` | `app.screenshot('label')`、比較するには [`toHaveScreenshot`](/visual-testing) |
| `device.getPlatform()` | `platform` フィクスチャ |
| テスト名の `:ios:` / `:android:` | テストに `{ platforms: ['ios'] }` |

## e2e にまだないもの

「予定あり」はロードマップにあるもの、「未定」は時期が決まっていないものです。
「予定なし」は意図的に含めていないものです。

### 予定あり

| Detox | 現時点での代替 |
| --- | --- |
| アプリを起動する `beforeAll` | `beforeEach` 内の `app.open()` |
| `artifacts.plugins.log`, `--record-logs` | CI のステップで `adb logcat` または `xcrun simctl spawn booted log stream` |
| `by.id('x').and(by.text('y'))` | `.filter({ hasText })`、または `device.locator('id=x label="y"')` |
| `system.element(by.system.label('Allow'))` | `device.alert('accept' \| 'dismiss')`、またはプロンプトが表示されないように `app.permissions` |
| `.longPressAndDrag()`, `.swipe()` のオフセット, `.multiTap(3)` | `.dragTo(target)`, `screen.swipe({ from, to })`, `.tap()` の繰り返し |
| `.scrollTo('bottom')` | `list.scrollUntilVisible(lastRow)`、または `{ direction: 'up' }` で最初の行 |
| `.tapBackspaceKey()` | 短くしたテキストで `.fill(t)` |
| `.setDatePickerDate()`, `.setColumnToValue()`, `.adjustSliderToPosition()` | `agent.act` のゴール、またはスライダーに対して `screen.swipe({ from, to })` |
| フォームコントロール以外での `.toHaveValue(v)` | `expect(device.locator('id=x value="v"')).toBeVisible()` |
| `health`、`homekit`、`speech`、`faceid`、`userTracking` の `permissions`、値 `always`、`inuse`、`limited` | プロンプトのボタンをタップするか、`device.alert('accept')` |
| `device.sendUserNotification()`, `device.uninstallApp()`, `.pinch()` | [`unstable_raw`](/reference/mobile#unstable_raw) の `client.apps.push()`, `client.apps.uninstall()`, `client.interactions.pinch()` |
| `launchApp({ languageAndLocale })` | iOS では `app.launchArguments: ['-AppleLanguages', '(fr)', '-AppleLocale', 'fr_FR']`。[アプリを別の言語で実行する](/mobile#run-the-app-in-another-language)を参照してください |
| Jest `globalSetup`, `globalTeardown` | 実行前に依存サービスを起動します |
| `device.reverseTcpPort()` | CI のステップで `adb reverse` を実行します |
| `device.shake()` | - |
| 1 つのキーと値のマップとしての `launchArgs` | iOS では `['-key', 'value']`、Android では `['--es', 'key', 'value']` |
| `.getAttributes()` | `.textContent()`, `.inputValue()`, `.isEnabled()`, `.isVisible()`, `.isChecked()`, `.boundingBox()` |
| `device.setStatusBar()` | `xcrun simctl status_bar`。`toHaveScreenshot` はステータスバーを固定します |

### 未定

| Detox | 現時点での代替 |
| --- | --- |
| `.toBeVisible(50)`、およびデフォルトの 75% | `.toBeVisible()` は面積ではなくプラットフォームのフラグを確認します。`.boundingBox()` で比較してください |
| `web.element(by.web.cssSelector('x'))` | WebView のアクセシビリティテキストとラベル、または `agent.act` のゴール |
| `device.resetContentAndSettings()` | `app.clearState()`、iOS ではさらに `device.clearKeychain()` |
| `device: { type, os }`, `headless`, `bootArgs` | CI のステップでデバイスを作成して起動します |

### 予定なし

| Detox | 代わりに使うもの |
| --- | --- |
| `device.reloadReactNative()` | `app.restart()`。リロードにはアプリ内の Detox フレームワークが必要です |
| `device.disableSynchronization()`, `enableSynchronization()` | 呼び出しを削除します。オフにする同期処理はありません |
| `device.setURLBlacklist()` | 呼び出しを削除します。ネットワーク通信がアクションをブロックすることはありません |
| init 時のインストール, `behavior.init.reinstallApp`, `--reuse` | フィクスチャ内の `device.installApp()` |
| `apps.<name>.build`, `detox build` | `e2e run` の前に通常のビルド |
| 正確なオフセットでの `.scroll()` | `screen.swipe({ from, to })` |
| `by.type('RCTImageView')` | `device.locator('role=image')`、または `testID` |
| Jest のレポーター, Allure | `junit` レポーター、またはカスタムレポーター |

## 意図的に異なる点

- e2e はアプリがアイドルになるのを待ちません。アクションは待機し、アサーションはリトライします。
  まだ表示されていないコントロールには [`transition`](/reference/mobile#transition) を、
  エージェントのアクションには [`settle`](/reference/mobile#settle) を引き上げてください。
- エンジンは自動では何もインストールしません。`device.installApp()` を呼び出してください。
- [ロケーター](/reference/screen)は厳密です。複数に一致した状態でのアクションは
  `LOCATOR_AMBIGUOUS` で失敗します。`.filter()`、`.first()`、`.nth()` で絞り込んでください。
- デバイスには `test.setup` も `{ session }` もありません。
  [Web との違い](/mobile#what-differs-from-the-web)を参照してください。
