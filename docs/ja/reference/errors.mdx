ランナーのエラーはすべてクラスとコードを持ちます。クラスは終了コードを決め、
コードは原因を示します。どちらもモデルが選ぶことはありません。例外は
`e2e login`、`e2e logout`、`e2e models` で、
[終了コード](#exit-codes)で説明しています。

```ts title="tests/upgrade.e2e.ts"
import { isAgentError, test } from 'e2e';

test('upgrade to Pro', async ({ agent }) => {
  try {
    await agent.act('upgrade the workspace to Pro');
  } catch (error) {
    if (isAgentError(error) && error.code === 'STEP_TIMEOUT') {
      // the step ran out of time; the message carries the last judgment
      console.error(error.category, error.details);
    }
    throw error;
  }
});
```

## リファレンス

### 終了コード

| クラス | 終了コード |
| --- | ---: |
| test | 1 |
| configuration | 2 |
| infrastructure | 3 |
| internal | 4 |
| interrupted | 130 |

- 結果が混在する実行では、存在するコードのうち優先度が最も高いものが採用されます
  (`130 > 4 > 3 > 2 > 1 > 0`)。レポートには個々の結果がすべて残ります。
- クリーンアップに失敗したテスト(必須のビデオが確定されなかった、セッションが
  閉じられなかったなど)は、そのクリーンアップエラーのコード(通常は 3)で
  終了します。
- セットアップのアサーション失敗はテストの失敗であり、それに依存するテストを
  スキップします。セットアップのインフラストラクチャが欠けている場合は、
  configuration または infrastructure のクラスのままです。
- `internal` クラスと終了コード 4 は、ランナーの不変条件違反のために予約されて
  います。現在、このクラスのコードを発生させるファーストパーティのコードは
  ありません。
- `e2e login`、`e2e logout`、`e2e models` は、失敗のメッセージをコードなしで
  表示して 1 で終了します。サインインやピッカーがキャンセルされた場合は 130 で
  終了します。

| コード | 説明 |
| --- | --- |
| [エージェントコード](#agent-codes) | `AgentError` の `code` |
| [ランナーコード](#runner-codes) | 出力とレポートに含まれるプレーンな文字列 |
| [テストコードのエラー](#test-code-errors) | テストコードからスローされるもの |

### AgentError

`AgentError` はランナーが分類したエージェントの失敗で、`e2e` からエクスポート
されています。

```ts
/** Runner-classified agent failure. */
export class AgentError extends Error {
  /** Closed union, assigned by the runner, never taken from model text. */
  readonly code: AgentErrorCode;
  /** The error class in the table above; it sets the exit code. */
  readonly category: 'test' | 'configuration' | 'infrastructure' | 'internal' | 'interrupted';
  readonly retryable: boolean;
  /** Structured facts: locator, expected, observed, match count, wait time. */
  readonly details: ErrorDetails | undefined;
  /** Sanitized, bounded prose; the same value as `message`. */
  readonly explanation: string;
  /** Artifact path, present only when evidence was captured and permitted. */
  readonly screenshot?: string;
  /** True when this failure reports a blocked step, not a product failure. */
  readonly blocked: boolean;
}
```

<Note>
テストファイルは独自のモジュールレルムで読み込まれるため、`instanceof AgentError`
が false になることがあります。このページ冒頭の例のように、`e2e` の
`isAgentError` を使い、`code` で分岐してください。
</Note>
