`@e2e-dev/web` はブラウザエンジンです。Playwright を通じて Chromium、Firefox、WebKit
を駆動します。Web ターゲットは `web()` でこれをエンジンとして指定し、エンジンは
ブラウザ専用の操作のための `browser` フィクスチャを提供します。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';

export default {
  targets: [{ engine: web(), app: { url: 'http://localhost:3000' } }],
} satisfies E2EConfig;
```

`browser` に型を付けるには、パッケージから `test` をインポートします。

```ts title="tests/orders.e2e.ts"
import { expect } from 'e2e';
import { test } from '@e2e-dev/web';

test('orders in dark mode', async ({ app, browser, screen }) => {
  await browser.emulateMedia({ colorScheme: 'dark' });
  await app.open('/orders');
  await expect(browser).toHaveURL('/orders');
  await expect(screen.getByRole('heading', { name: 'Orders' })).toBeVisible();
});
```

## リファレンス

### オプション

`web(options)` は、エンジンがアプリをどのように駆動するかを設定します。アプリ自体
（その `url`、`environment`、`identity`、およびアプリを起動するコマンド）は
ターゲットの `app` で、
[テスト対象のアプリ](/reference/config#the-app-under-test)で説明しています。

```ts
web({ viewport: { width: 390, height: 844 }, locale: 'de-DE' });
```

| オプション | 型 | デフォルト |
| --- | --- | --- |
| [`browser`](#browser) | `BrowserName \| BrowserProvider` | `'chromium'` |
| [`viewport`](#viewport) | `ViewportSize \| null` | 1280 × 720 |
| [`screencast`](#screencast) | `WebScreencastOptions` | ビューポートのサイズ |
| [`connect`](#connect) | `WebConnectOptions` | ローカルで起動 |
| [`headers`](#headers) | `Record<string, string>` | - |
| [`basicAuth`](#basicauth) | `WebBasicAuth` | - |
| [`credentialOrigins`](#credentialorigins) | `string[]` | - |
| [`testIdAttribute`](#testidattribute) | `string` | `'data-testid'` |
| [`userAgent`](#useragent) | `string` | ブラウザ自身の値 |
| [`locale`](#locale) | `string` | ブラウザ自身の値 |
| [`timezoneId`](#timezoneid) | `string` | マシンの値 |
| [`colorScheme`](#media-emulation) | `'light' \| 'dark' \| 'no-preference'` | ブラウザ自身の値 |
| [`reducedMotion`](#media-emulation) | `'reduce' \| 'no-preference'` | ブラウザ自身の値 |
| [`initScripts`](#init-scripts) | `WebInitScript[]` | - |

- `web()` ターゲットには `app.url` が必要で、デバイス用のキー（`bundleId`、
  `appPath`、`launchArguments`）は拒否されます。その `app.permissions` は、
  ブラウザが付与する名前に対する `'grant'` のみを受け付けます。
  [`permissions`](/reference/config#permissions) を参照してください。
- `app.url` を持つターゲットは `browser` ターゲットなので、`requires: ['browser']`
  で Web ターゲットを選択できます。
- JSDoc を含む完全な宣言は、型セクションの [`WebOptions`](#weboptions) にあります。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | `web()` が受け付けないオプション（`url` やその他のアプリのキーを含む）、または `connect` や `basicAuth` 内の未知のキーです。メッセージには、タイプミスと思われる場合は最も近い既知のキー（`viewprt` なら `viewport`）、そうでなければすべてのキーが示されます。 |
| `INVALID_CONFIG` | [永続コンテキスト](#recovering-a-cdp-transport)（`connect.reconnectEndpoint`、または `scope: 'attempt'` のプロバイダー）での `headers`、`basicAuth`、`userAgent`、`locale`、`timezoneId` です。 |

#### `browser`

起動するブラウザ、またはホスト型ブラウザをリースするプロバイダーです。

```ts
web({ browser: 'firefox' }); // default: 'chromium'
```

- `'chromium'`、`'firefox'`、`'webkit'` のいずれかです。
- `BrowserProvider` は、代わりにホスト型ブラウザをリースします。実行中のワーカースロット
  ごとに 1 つ、または試行ごとに 1 つです（[`WebOptions`](#weboptions)）。エンジンは、
  それが Chromium であっても、[Lightpanda](/integrations/lightpanda) や
  [Moli](/integrations/moli) のような別の CDP サーバーであっても、それぞれを CDP 経由の
  chromium として駆動します。
- `scope: 'attempt'` のプロバイダーは永続コンテキストを使い、
  [CDP トランスポートの復旧](#recovering-a-cdp-transport)に記載の制限を受けます。
- [ホスト型ブラウザ](/browser#hosted-browsers)には、`BrowserProvider` の
  コントラクトとプロバイダーの例があります。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | `browser: provider` と `connect` を同時に指定した場合です。 |

#### `viewport`

すべての試行のページの初期ビューポートです。

```ts
web({ viewport: { width: 390, height: 844 } }); // default: { width: 1280, height: 720 }
```

`null` はサイズをエミュレートしないため、ページはブラウザウィンドウ全体に広がります
（[`WebOptions`](#weboptions)）。それでも [`browser.setViewport`](#setviewport) で
サイズを固定できます。

#### `screencast`

ビデオを録画する試行を、エンジン自身のスクリーンキャストがどのように録画するかを指定します。

```ts
web({ screencast: { size: { width: 800, height: 450 }, quality: 60 } });
```

- `size` は整数のピクセルで、各辺は 1 以上です。`quality` は整数です。
- どの試行を録画するかは、設定の [`video`](/reference/config#video) モードで決まります。

```ts
/** The engine's screencast of the page: the frame size and the JPEG quality of the frames it encodes. */
export interface WebScreencastOptions {
  /** Frame size in pixels; default the viewport's, or the window's under `viewport: null`. A smaller size makes a smaller file. */
  readonly size?: ViewportSize;
  /** JPEG quality of each captured frame, 0 through 100; Playwright's default when unset. */
  readonly quality?: number;
}
```

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | 設定の読み込み時に、上記以外の `size` や `quality` の値、または別のキーがある場合です。古い `web({ video })` という書き方も拒否され、`screencast` が案内されます。 |

#### `connect`

ローカルでブラウザを起動する代わりに、CDP 経由でリモートブラウザに接続します。

```ts
web({ connect: { cdpEndpoint: async () => 'ws://127.0.0.1:9222' } });
```

`reconnectEndpoint` を指定すると永続コンテキストを使います。
[CDP トランスポートの復旧](#recovering-a-cdp-transport)を参照してください。

どちらのリゾルバーも、CDP ハンドシェイクを認証するために `{ endpoint, headers }` を `CdpTarget` として返すことができます。これらのヘッダーは、アプリにヘッダーを送る `web({ headers })` とは別のものです。

```ts
interface WebConnectOptions {
  cdpEndpoint(signal: AbortSignal): string | CdpTarget | Promise<string | CdpTarget>;
  reconnectEndpoint?(signal: AbortSignal): string | CdpTarget | Promise<string | CdpTarget>;
}
```

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | 設定の読み込み時に、`connect` に `cdpEndpoint` がない場合、または文字列として指定された場合です。`browser` プロバイダーと並べて `connect` を指定した場合も同様です。 |

##### CDP トランスポートの復旧

`connect.reconnectEndpoint(signal)` を指定すると、CDP トランスポートが切断された後に
同じリモートブラウザを復旧します。分離されたコンテキストを維持するには、これを省略します。

リモートブラウザの要件:

- リトライを含むすべての試行で、`cdpEndpoint` から新しいブラウザが必要です。
  1 つの長時間稼働するブラウザでスイート全体をまかなうことはできません。
- リモートにはデフォルトコンテキストだけが存在している必要があります。
- 試行が終了したら、ホストがブラウザを削除する必要があります。エンジンの
  クリーンアップは接続を切り離すだけで、ホストのブラウザを終了しません。
- 試行の最初のページは、ブラウザ自身の最初のタブを `about:blank` に移動したもので、
  その横の 2 つ目のタブではありません。`app.restart` が開くページのように、後から
  開かれたページは新しいタブです。

復旧の流れ:

- 切断後、次の操作がその操作のタイムアウトと中断シグナルの範囲内で
  `reconnectEndpoint` を 1 回呼び出します。リゾルバーは既存のブラウザの
  エンドポイントを返す必要があります。
- エンジンは、永続的なデフォルトコンテキスト ID とアクティブなタブのターゲット ID を
  確認します。デフォルトコンテキスト ID を公開しないブラウザは拒否します。アクティブな
  タブがない場合やコンテキストが異なる場合、試行は失敗します。URL が一致しても代わりの
  タブは選択されません。試行の他のタブはターゲット ID で見つけ、なくなったタブは
  除外します。
- エンジンは、各 CDP バインディングを公開する前にセキュアフィールドのマスキングを
  導入します。互換性のない Playwright バージョンでは、ピクセルを露出させる代わりに
  接続が失敗します。
- 元のページのフレームは、closed な Shadow DOM の追跡フックを保持している必要が
  あります。既存の closed ルートは、アプリケーションを再読み込みしない限り復旧できません。
  マスクのクエリは、追跡されていないドキュメントをすべて拒否します。
- エンドポイントの解決、CDP への接続、セットアップ、ディスパッチは 1 つのタイムアウトを
  共有します。並行して待機している呼び出しをキャンセルしても、復旧を開始した操作は
  キャンセルされません。その復旧の所有者をキャンセルすると、共有の復旧が失敗します。

| 例外 | 発生条件 |
| --- | --- |
| `ENGINE_FAILURE` | 切断中に、closed な Shadow DOM のフックなしでドキュメントが読み込まれた場合です。 |
| `OPERATION_TIMEOUT` | エンドポイントの解決、接続、セットアップ、ディスパッチが共有のタイムアウトを使い切った場合です。 |
| `CANCELLED` | 呼び出し元または試行がキャンセルした場合です。 |

維持されるもの:

- 復旧では、ページの未保存の状態、ストレージ、エージェントの台帳が維持されます。ダイアログとルートのハンドラーは再登録されます。
- ビデオ録画は再開されます。切断中に失われたセグメントは戻りません。
- すでにディスパッチされた操作がリトライされることはありません。
- 復旧によって古いノード参照はクリアされます。観測から得た `tapAt` と
  `doubleTapAt` の呼び出し、観測ルートのスワイプ、フォーカスされたエンジンのキーボード入力は、
  再開する前に新しいエンジンの観測が必要です。
- 復旧前に開始された観測やロケーターの読み取りは、接続が変わった後に参照を公開できません。
  各試行はそれぞれのバインディングと録画を所有するため、遅れて行われたクリーンアップが
  後の試行を変更することはありません。
- 決定論的な `browser.mouse` と `browser.keyboard` フィクスチャは、エージェントの
  観測なしでも引き続き使用できます。テストコードは自身の入力を管理し、操作の前に
  `browser.evaluate` で現在のジオメトリとフォーカスを読み取れます。
- `surfaceOf(engine)` を使うコードは、復旧後にアクセサーを読み直す必要があります。
  保持していた Playwright オブジェクトは切断されたトランスポートに属しています。

`scope: 'attempt'` の `browser` プロバイダーは、同じ制限のもとで同じ永続コンテキストを
使います。リースの `cdpEndpoint` が試行のブラウザを用意し、その `reconnectEndpoint`
（なければ再び `cdpEndpoint`）でそのブラウザに再接続します。リースはプロバイダーの
コントラクトにより新しいものなので、エンジンはそのコンテキストを以前の試行のものと
比較しません。ホスト型サービスは 1 つのスナップショットからブラウザを復元することがあり、
その場合、新しいブラウザが同じコンテキスト ID を持ちます。

複数のファイルで 1 回のサインインを再利用するには、分離されたコンテキストを維持し
（`reconnectEndpoint` なし、プロバイダーの `scope: 'attempt'` なし）、
[セットアップテストで 1 回サインインします](/authentication#reuse-authenticated-sessions)。
サインインを運ぶのは共有ブラウザではなく、保存されたセッションです。

<Note>
永続コンテキストは、`headers`、`basicAuth`、`userAgent`、`locale`、`timezoneId`
（[オプション](#options)を参照）、`app.clearState`、セッション状態の取得と復元を
サポートしません。`app.clearState` は `UNSUPPORTED_CAPABILITY` で失敗します。
`app.restart` は引き続き使用できます。
</Note>

#### `headers`

アプリのオリジン（`app.url` のスキーム、ホスト、ポート）から開始されるすべての
リクエストに追加されるヘッダーです。別のポート、サブドメイン、その他のホストから
開始されるリクエストには付きません。リダイレクトは、元のリクエストが開始時に
持っていたヘッダーを、どのオリジンに対しても維持します。

```ts
web({ headers: { 'x-preview-token': process.env.PREVIEW_TOKEN ?? '' } });
```

- 許可されたオリジン宛ての [continue された](#route)リクエストにも引き続き付きます。
- `headers` と `basicAuth` は、テストが
  [保護されたプレビュー](/web#protected-previews)にアクセスするための手段です。
- [リクエストの認証情報](/reference/security#request-credentials)を参照してください。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | [`userAgent`](#useragent) と並べた `user-agent` エントリー、または [`locale`](#locale) と並べた `accept-language` エントリーです。 |

<Note>
`headers` はリクエストのルーティングを有効にします。これにより、ブラウザの HTTP
キャッシュが無効になり、Service Worker がブロックされます。
</Note>

#### `basicAuth`

HTTP Basic 認証です。ブラウザは、アプリのオリジンからの `401` チャレンジに
これらの認証情報で応答します。その他のオリジンからのチャレンジには、
[`credentialOrigins`](#credentialorigins) に記載されていない限り応答しません。

```ts
import { secrets } from 'e2e';

web({ basicAuth: { username: 'staging', password: secrets.get('staging-password') } });
```

`secrets.get(name)` のパスワードは各試行の開始時に解決され、設定された他の
シークレットと同様にリダクトされます。それが変換された `Authorization` ヘッダーの
base64 の認証情報も同様です。

```ts
/** HTTP basic authentication the browser answers a `401` challenge from the app's origin with. */
export interface WebBasicAuth {
  /** The user name; `:` is not allowed in one (RFC 7617). */
  readonly username: string;
  /** The password, or `secrets.get(name)` for one in `config.secrets`. */
  readonly password: string | Secret;
}
```

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | ユーザー名に `:` が含まれる場合、または未知のキーがある場合です。 |

<Note>
WebKit は、スキームのデフォルトポート上のオリジン（`https://staging.example.com`）
や IPv6 ホストのオリジンに認証情報を限定できません。アプリのオリジンまたは
`credentialOrigins` 内のオリジンがそのようなオリジンである場合、WebKit は
Playwright のデフォルトと同じく、どのオリジンからの `401` にも応答します。
</Note>

<Warning>
シークレットの保護はテキストのみが対象です。パスワードを画面に表示するページは、
スクリーンショットやモデルのピクセルではマスクされません
（[セキュリティのルール](/reference/security#secrets-in-engine-options)）。
</Warning>

#### `credentialOrigins`

アプリ自身のオリジンに加えて [`headers`](#headers) と
[`basicAuth`](#basicauth) を受け取るオリジンです。同じゲートの背後にある別ホストの
API などが該当します。

```ts
web({
  headers: { 'x-preview-token': process.env.PREVIEW_TOKEN ?? '' },
  credentialOrigins: ['https://api.staging.example.com'],
});
```

各オリジンは正確に記載してください。ホスト内の `*` やポート `0` はどのリクエストにも
一致しません。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | `headers` も `basicAuth` もない場合、パス・クエリ・フラグメントを持たない `http:` または `https:` のオリジンではないエントリー、ホスト内の `*`、またはポート `0` です。 |

#### `testIdAttribute`

要素のテスト ID を持つ属性です。`testId` クエリ（`screen.getByTestId`）が解決し、
`SemanticNode.testId` が報告する属性です。

```ts
web({ testIdAttribute: 'data-test' }); // default: 'data-testid'
```

#### `userAgent`

すべての試行のコンテキストが送信し、`navigator.userAgent` が報告する `User-Agent` です。
エージェント文字列内のマーカーでテストモードに切り替わるアプリ向けです。

```ts
web({ userAgent: 'Mozilla/5.0 e2e' }); // default: the browser's own
```

#### `locale`

すべての試行のコンテキストが実行されるロケールで、BCP 47 タグです。
`navigator.language`、`Intl` の書式設定、`Accept-Language` ヘッダーが報告する値です。

```ts
web({ locale: 'de-DE' }); // default: the browser's own
```

#### `timezoneId`

すべての試行のコンテキストが実行される IANA タイムゾーンです。`Date` と `Intl` が
ローカル時刻を解決する基準になります。

```ts
web({ timezoneId: 'Europe/Berlin' }); // default: the machine's
```

#### メディアエミュレーション

`web({ colorScheme, reducedMotion })` は、Playwright の同名のコンテキストオプションと
同様に、すべての試行のすべてのページが報告するメディア特性を設定します。
`browser.emulateMedia(media)` は、1 つの試行に対してそれらを変更します。

```ts
web({ colorScheme: 'dark', reducedMotion: 'reduce' }); // default: the browser's own
await browser.emulateMedia({ colorScheme: 'light' });
```

- ページの `@media` ルールと `matchMedia` は、最初の描画からこれらを読み取ります。
- 永続コンテキストでもこれらのオプションを使えます。エンジンは開く各ページに
  それらを設定します。
- `emulateMedia` は試行の残りの期間、開いているすべてのタブとその後に開かれる
  すべてのタブに、`app.restart()` と `app.clearState()` を経ても適用されます。
- 最初のナビゲーションの前でも動作するため、次の `app.open` はその設定で読み込まれます。
- 指定しなかった特性は値を維持します。
- アプリ自身が開くタブには、永続コンテキストの場合も含め、タブが現れた時点で
  テストの変更が適用されます。そのため、読み込み時に実行されるスクリプトは、
  設定された値を読み取る可能性があります。

```ts
/** User preferences a page reads through `@media` rules and `matchMedia`. */
export interface WebMedia {
  /** `prefers-color-scheme`. */
  readonly colorScheme?: 'light' | 'dark' | 'no-preference';
  /** `prefers-reduced-motion`. */
  readonly reducedMotion?: 'reduce' | 'no-preference';
}
```

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_CONFIG` | `web()` で、`WebMedia` にない特性または値を指定した場合です。 |
| `INVALID_ARGUMENT` | `emulateMedia` で、`WebMedia` にない特性または値を指定した場合です。 |

#### 初期化スクリプト

初期化スクリプトは、すべてのタブとフレームのすべてのドキュメントで、ページ自身の
スクリプトより前に実行されます。`web({ initScripts })` はすべてのテストに適用され、
`browser.addInitScript` はテストの残りの期間に 1 つ追加します。

```ts
await browser.addInitScript((value) => { Math.random = () => value; }, 0.5);
await app.open('/raffle');
```

- 関数はテストの変数をクロージャーで参照できません。代わりに JSON の `arg` を渡します。
- ページが開いた後に追加されたスクリプトは、次のナビゲーションまたは再読み込みから
  実行されます。
- `browser.addInitScript` は同じ 3 つの形式、または JSON の `arg` を伴う関数を
  受け付けます。そのオーバーロードは [`Browser`](#browser-interface) にあります。

```ts
/** JavaScript source, a file relative to the project root, or a function. */
export type WebInitScript = string | { readonly path: string } | (() => unknown);
```

### browser フィクスチャ

`browser` はブラウザ全体を表し、1 つのアクティブなタブを表示します。

- ページを読み取ったりページに作用したりするものは、アクティブなタブに作用します。
  `goto`、`reload`、`back`、`forward`、`url`、`title`、`waitForURL`、`locator`、
  `frameLocator`、`evaluate`、`waitForResponse`、`waitForDownload`、`keyboard`、
  `mouse`、`expect(browser)` のマッチャー、そしてすべての `screen` クエリです。
- ブラウザに属するものは、すべてのタブを対象にします。`cookies`、`setCookies`、
  `clearCookies`、`route`、`unroute`、`unrouteAll`、`onDialog`、
  `addInitScript` です。
- `setViewport` は、アクティブなタブとその後に開かれるすべてのタブのサイズを設定します。
- [`emulateMedia`](#media-emulation) は、開いているタブと今後のすべてのタブのメディアを
  変更します。
- `target="_blank"` のリンクや `window.open` からアプリが開いたタブは、
  バックグラウンドで開きます。`waitForPopup` または `activate` で別のタブを
  アクティブにするまで、アクティブなタブは元のままです。[タブ](#tabs)を参照してください。
- `locator` と `frameLocator` を除き、すべての `browser` の呼び出しは
  `browser.<method>` ステップとして記録されます。この 2 つはページに触れずに
  ロケーターを構築し、それに対するアクションやアサーションがステップになります。
- 相対 URL はターゲットの `app.url` を基準に解決され、ない場合は
  `APP_URL_REQUIRED` になります。
- 他のプラットフォームでも実行するスイートでは、`requires: ['browser']` を宣言します。
- `expect(browser)` は、エンジンが付与する `BrowserExpectation` を返します。
  `toHaveURL`、`toHaveTitle`、`toHaveClass` です。
  [ブラウザのマッチャー](/reference/expect#browser-matchers)を参照してください。

[設定](/reference/config)は、各メンバーの時間の予算を決めます。

- `goto`、`reload`、`back`、`forward`: [`timeout`](/reference/config#timeout)。
  `app.open()` と同じ予算です。
- `waitForURL`: [`assertionTimeout`](/reference/config#assertiontimeout)。
- その他のすべてのメンバー: [`actionTimeout`](/reference/config#actiontimeout)。
  `locator` と `frameLocator` はページに触れないため、予算を取りません。

`{ timeout }` オプションは、`goto`、`reload`、`back`、`forward`、`waitForResponse`、
`waitForPopup`、`waitForDownload`、`waitForDownloads` の予算を上書きします。上限は
テストの期限（`afterEach` では `cleanupTimeout`）で、`0` を指定するとその期限まで
待ちます。`url`、`title`、`evaluate`、`addInitScript`、`route`、
`unroute`、`unrouteAll`、`cookies`、`setCookies`、`clearCookies`、`setViewport`、
`emulateMedia`、`onDialog`、`newTab`、`BrowserTab` のメソッド、`keyboard.*`、`mouse.*` は上書きを受け付けません。

#### `goto`

アクティブなタブを URL に移動します。

```ts
await browser.goto('/dashboard', { waitUntil: 'networkidle' }); // default: 'load'
```

`waitUntil` は `'load'`、`'domcontentloaded'`、`'networkidle'` のいずれかです。

| 例外 | 発生条件 |
| --- | --- |
| `POLICY_DENIED` | スキームが `http:` でも `https:` でもない URL の場合です。`about:blank` は許可されます。 |
| `APP_URL_REQUIRED` | `app.url` を宣言していないターゲットで、相対 URL を指定した場合です。 |
| `ACTION_FAILED` | ナビゲーションが失敗した場合です。 |

#### `reload`, `back`, `forward`

`reload` は現在のドキュメントを再読み込みします。`back` と `forward` はブラウザの
履歴を 1 回移動します。3 つとも、ドキュメントの読み込みを待ちます。back/forward キャッシュからの復元では、すでに読み込まれたドキュメントが再利用されることがあります。
アプリのコンテンツを待つには、ロケーターとアサーションを使ってください。

```ts
await browser.reload();
await browser.back({ timeout: 10_000 });
```

| 例外 | 発生条件 |
| --- | --- |
| `ACTION_FAILED` | ナビゲーションが失敗した場合です。 |

#### `url`, `title`

アクティブなタブの現在の URL とタイトルを返します。

```ts
const url = await browser.url();
const title = await browser.title();
```

#### `waitForURL`

現在の URL が一致するまで待ちます。開始から 0、20、50 ms の時点で URL を読み取り、
その後は 100 ms ごとに読み取ります。`expect(browser).toHaveURL` と同じポーリングです。

```ts
await browser.waitForURL(/\/orders\/\d+$/, { timeout: 15_000 });
```

- 相対的な文字列はベース URL を基準に解決され、正規化後に完全一致で比較されます。
- `RegExp` は URL 全体に対してテストされます。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_ARGUMENT` | 文字列でも `RegExp` でもないパターン（述語関数など）、または Playwright の `waitUntil` のような `timeout` 以外のオプションです。 |
| `ASSERTION_FAILED` | タイムアウトまでに URL が一致しなかった場合です。 |

#### `locator`

Playwright のセレクターから Web 専用のロケーターを作成します。

```ts
const conditions = browser.locator(
  '[data-testid="row"] >> nth=2 >> [data-testid="conditions"] > div',
);
```

- セレクターはデフォルトで CSS、`xpath=` または先頭の `//` で XPath になり、
  `>>` のチェーンを使えます。そのため、この例では CSS を 1 つの行に限定しています。
- 別の要素を含む要素には `filter({ has })` を使います。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_LOCATOR` | 空のセレクター、または最後の部分より前にある `*` キャプチャ（`*css=article >> text=Hello`）です。 |

<Note>
すべての `screen` クエリは、そのスコープと、ページがその下にアタッチした各 closed
Shadow ルートを検索します。マッチングには Playwright 自身のロール、名前、テキスト、
ラベル、属性のマッチングを使い、各ノードは 1 回だけ見つかります。観測されたツリーが
closed ルート内に記載しているコントロールは解決され、アクションと読み取りを受け付けます。
`locator`、`frameLocator`、`filter({ hasText })` は Playwright の到達範囲のままで、
closed ルートで止まります。詳細は[ブラウザガイド](/browser#shadow-dom)にあります。
</Note>

#### `frameLocator`

1 つの iframe 内にスクリーンクエリのスコープを作成します。

```ts
const payment = browser.frameLocator('#payment-frame');
await payment.getByLabel('Card number').fill('4242424242424242');
```

これは `FrameScreen` を返します。これは、クエリがフレーム内から応答する `Screen` です。
フレームの `locator` は、コントロールにアクセシブルな名前、ラベル、プレースホルダー、
テスト ID のいずれもない場合にのみ使ってください。
[ブラウザガイド](/browser#reach-into-an-iframe)に、それが当てはまる場合が示されています。

```ts
export interface FrameScreen extends Screen {
  /** Creates a web-only CSS or XPath locator inside this frame. */
  locator(selector: string): Locator;
  /** Creates a screen query scope inside an iframe nested in this frame. */
  frameLocator(selector: string): FrameScreen;
}
```

エラーはページでもフレーム内でも同じです。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_LOCATOR` | ここまたはフレームの `locator` で、空のセレクターを指定した場合です。 |
| `LOCATOR_NOT_FOUND` | 一致するフレームがない場合です。 |
| `LOCATOR_AMBIGUOUS` | 複数のフレームが一致する場合です。 |

#### `evaluate`

信頼されたテストコードをページ内で評価し、その結果を返します。

```ts
const count = await browser.evaluate(() => document.querySelectorAll('li').length);
const flag = await browser.evaluate(
  (name: string) => window.localStorage.getItem(name),
  'featureFlags',
);
const title = await browser.evaluate<string>('document.title');
```

- 関数はページ内で実行され、テストの変数にはアクセスできません。
  e2e は関数をソースコードでシリアライズしてページにインライン化するため、関数は
  自身の本体の外にあるものをクロージャーで参照してはいけません。本体内で宣言した
  ヘルパーは動作します。外部の値は `arg` で渡してください。
- 文字列は、文の並びではなく単一の式として評価されます。評価結果が関数の場合は、
  その関数が `arg` を引数に呼び出されます。そうでなければ、その値が結果になります。
- どちらの場合も、Promise は await されます。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_ARGUMENT` | `arg` または戻り値が [`JsonValue`](#jsonvalue) ではない場合です。`DOMRect` や要素などのクラスインスタンスは該当しません。`rect.toJSON()` または必要なフィールドを返してください。 |
| `EVALUATE_FAILED` | 評価したコードがスローした場合、またはエンジンが必要とする `Map` などの JavaScript 組み込みオブジェクトをページが置き換えた場合です。エラーにはメッセージが含まれます。 |
| `ACTION_FAILED` | Playwright のタイムアウトです。 |
| `ENGINE_FAILURE` | ページが閉じた場合、またはコンテキストが失われた場合です。 |

#### `route`

試行スコープのネットワークルートを追加します。

```ts
await browser.route('**/api/quote', async (route) => {
  await route.fulfill({ json: { cents: 4200 } });
});
```

`route.fetch()` は、ルートを決定することなく、アクションのタイムアウト内で、
オリジンが対象であれば設定されたヘッダーを付けて、上流の
`{ url, status, headers, body(), text(), json() }` を返します。
ナビゲーションのルールを迂回する可能性があるため、リダイレクトには従いません。

- パターンは文字列または `RegExp` で、どちらも URL 全体に対してテストされます。
  文字列では、`*` はパスセグメント内、`**` は `/` をまたいで一致し、`?` は任意の
  1 文字、`\` は次の文字をエスケープします。`unroute` と `waitForResponse` も
  同じパターンを受け付けます。
- ルートは `app.restart()`、`app.clearState()`、セッションの復元を経ても維持されます。
- ルートは新しいものから順に実行されます。
- ハンドラーは、下の `WebRoute` で説明する `fulfill`、`continue`、`fallback`、
  `abort` のいずれかで、ちょうど 1 回決定する必要があります。
- `continue` の URL には `goto` と同じルールが適用されます。`continue` で
  `undefined` に設定したヘッダーは、リダイレクト時も含めて削除されます。
- `fulfill` の本文は文字列またはバイト列（`Buffer`、`Uint8Array`）で、そのまま送信されます。
- 複数の Cookie を設定するには、`route.fetch()` のヘッダーが報告するのと同様に、
  1 つの `set-cookie` ヘッダー内で `\n` で連結します。ヘッダー内のその他の改行は拒否されます。
- スローしたハンドラー（リクエストに対する `expect` が失敗した場合など）は、その
  エラーで次のステップを失敗させます。後続のステップがない場合は、試行の終了時に
  試行を失敗させます。ハンドラーが失敗させたステップ（ハンドラーがリクエストを
  中断したままにした `goto` など）は、ハンドラーのエラーで失敗します。ハンドラーが
  意図的にリクエストを中断した `goto` は `ACTION_FAILED` で失敗します。
  その時点でまだ実行中のハンドラーには、完了するためのクリーンアップの予算が与えられます。
  予算を過ぎた後にスローしたものは破棄されます。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_ARGUMENT` | パターンとして述語関数を指定した場合です。また、決定が受け付けないオプション（Playwright の `abort(errorCode)`、スペルミスのキーなど）の場合も該当し、リクエストは中断され、次のステップが失敗します。 |
| `ACTION_FAILED` | ハンドラーが 2 回決定した場合、または一度も決定しなかった場合です。 |
| `POLICY_DENIED` | 禁止されたスキームの `continue` URL です。 |
| `CLEANUP_TIMEOUT` | ハンドラーがクリーンアップの予算を超えて実行された場合です。試行は失敗します。 |

```ts
/**
 * One of `json`, `body`, or `path`, or none for an empty body. `path` names a
 * file relative to the project root; its `Content-Type` follows its
 * extension unless `contentType` or a `content-type` header sets one.
 */
export type RouteFulfillResponse = {
  status?: number;
  /** Response headers; `set-cookie` may join several cookies with `\n`, as `route.fetch()` reports them. */
  headers?: Record<string, string>;
  /** Sets the `Content-Type` response header. */
  contentType?: string;
} & (
  | { json: JsonValue; body?: never; path?: never }
  | { body: string | Uint8Array; json?: never; path?: never }
  | { path: string; json?: never; body?: never }
  | { body?: never; json?: never; path?: never }
);

/** What `continue` changes about the request before it goes to the network. */
export interface RouteContinueOverrides {
  /** Resolved against the base URL like `goto`; must keep the request's scheme. */
  url?: string;
  /** Request method. */
  method?: string;
  /** Replaces every request header; `undefined` drops one, and the configured `headers` for an allowed origin are added on top. */
  headers?: Record<string, string | undefined>;
  /** Request body. */
  postData?: string;
}

export interface WebRoute {
  /** The intercepted request. */
  readonly request: {
    readonly url: string;
    readonly method: string;
    readonly headers: Readonly<Record<string, string>>;
    readonly postData?: string;
  };
  /** Reads upstream without deciding the route or following redirects. */
  fetch(): Promise<WebResponse>;
  /** Fulfills the intercepted request once. */
  fulfill(response: RouteFulfillResponse): Promise<void>;
  /** Sends the intercepted request to the network once, skipping every other route. */
  continue(overrides?: RouteContinueOverrides): Promise<void>;
  /** Hands the intercepted request to the route registered before this one, or the network when none matches. */
  fallback(): Promise<void>;
  /** Aborts the intercepted request once. */
  abort(): Promise<void>;
}
```

#### `unroute`

パターンに一致する試行スコープのルートを削除します。パターンは [`route`](#route) の
パターン構文で指定します。

```ts
await browser.unroute('**/api/quote');
```

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_ARGUMENT` | パターンとして述語関数を指定した場合です。 |

#### `unrouteAll`

browser フィクスチャが登録したすべてのルートを削除します。設定されたヘッダーは維持されます。

```ts
await browser.unrouteAll();
```

#### `waitForResponse`

パターンに一致するレスポンスを待ちます。パターンは [`route`](#route) のパターン構文で
指定します。

```ts
const response = await browser.waitForResponse('**/api/orders');
expect(response.status).toBe(201);
```

- 期限は一致の待機にかかります。レスポンスはヘッダーが届いた時点で解決されます。
- `body()`、`text()`、`json()` は、テストの期限を上限とする
  `config.actionTimeout` という独自の予算で本文を待ちます。
- `url`、`status`、`headers` はいつでも読み取れます。
- 本当に空の本文は、`body()` からは空の `Buffer`、`text()` からは `''` として
  読み取られます。`json()` はそれを拒否します。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_ARGUMENT` | パターンとして述語関数を指定した場合です。 |
| `ACTION_FAILED` | 期限内に何も一致しなかった場合です。`body()`、`text()`、`json()` では、予算が尽きた時点で本文がまだストリーミング中の場合、またはブラウザが読み取れなかった本文（宣言された `Content-Length` に満たないままの接続リセット、ページが中断したリクエスト、ブラウザが本文を保持しないリダイレクト）の場合に、空文字列ではなくこのエラーになります。 |

```ts
export interface WebResponse {
  /** Response URL. */
  readonly url: string;
  /** HTTP status. */
  readonly status: number;
  /** Response headers, lower-cased names; `route.fetch()` joins several `set-cookie` values with `\n`, `waitForResponse` leaves cookie headers out. */
  readonly headers: Readonly<Record<string, string>>;
  /** Waits for the body and returns its bytes. */
  body(): Promise<Buffer>;
  /** Waits for the body and parses it as JSON. */
  json<T = unknown>(): Promise<T>;
  /** Waits for the body and reads it as text. */
  text(): Promise<string>;
}
```

#### `cookies`

現在のコンテキストから見える Cookie を返します。

```ts
const cookies = await browser.cookies();
```

#### `setCookies`

すべての Cookie を検証してから設定します。

```ts
await browser.setCookies([{ url: 'http://localhost:3000', name: 'tz', value: 'UTC' }]);
```

- 相対的な `url` は、`goto` と同様にベース URL を基準に解決されます。
- `domain` 形式では、スキームはベース URL に従い、先頭の `.` は取り除かれます。

| 例外 | 発生条件 |
| --- | --- |
| `POLICY_DENIED` | 解析できないターゲット、または禁止されたスキームの場合です。何も設定されません。 |

```ts
export interface CookieFields {
  /** Cookie name. */
  name: string;
  /** Cookie value. */
  value: string;
  /** Unix timestamp in whole seconds. */
  expires?: number;
  /** HttpOnly flag. */
  httpOnly?: boolean;
  /** Secure flag. */
  secure?: boolean;
  /** SameSite attribute. */
  sameSite?: 'Strict' | 'Lax' | 'None';
}

/** `url`, or `domain` with an optional `path`, never both. */
export type Cookie = CookieFields &
  (
    | { url: string; domain?: never; path?: never }
    | { url?: never; domain: string; path?: string }
  );
```

#### `clearCookies`

`clearCookies({ name?, domain?, path? })` は、指定したすべてのフィルターに一致する
Cookie を削除します。文字列は完全一致、RegExp はフィールドに対してマッチします。
オプションを指定しない場合は、すべての Cookie を削除します。その他のストレージは残ります。

```ts
await browser.clearCookies({ name: /^session/, path: '/' });
```

```ts
export interface CookieFilter {
  name?: string | RegExp;
  domain?: string | RegExp;
  path?: string | RegExp;
}
```

#### `setViewport`

ビューポートのサイズを設定し、新しいサイズをレポートに記録します。

```ts
await browser.setViewport({ width: 390, height: 844 });
await app.open('/');
```

- Playwright の `setViewportSize` と同様に、最初のナビゲーションの前でも動作します。
  次の `app.open` はそのサイズで読み込まれるため、スマートフォンサイズのテストが
  最初にデスクトップのレイアウトを描画することはありません。
- サイズは試行の残りの期間、`app.restart()` と `app.clearState()` を経ても維持されます。

#### `onDialog`

ネイティブダイアログ用の試行スコープのハンドラーを登録し、登録解除の関数を返します。

```ts
const off = await browser.onDialog('accept');
await screen.getByRole('button', 'Delete').tap();
await off();
```

- ハンドラーは `'accept'`、`'dismiss'`、または `Dialog` を受け取る関数です。
- 関数のハンドラーは `accept` または `dismiss` を呼び出す必要があります。どちらも
  呼び出さない場合、処理されないダイアログと同様に、ダイアログは閉じられます（dismiss）。
- スローしたハンドラーは、そのエラーで次のステップを失敗させます。後続のステップが
  ない場合は、試行の終了時に試行を失敗させます。応答する前にスローした場合、その
  ダイアログは閉じられます（dismiss）。

エラーは `onDialog` ではなく、次のステップで表面化します。

| 例外 | 発生条件 |
| --- | --- |
| `APP_NOT_OPEN` | 関数のハンドラーがどちらの応答もしなかった場合、またはどのハンドラーもダイアログを処理しなかった場合です。 |
| `ASSERTION_FAILED` | ハンドラーの `expect` が失敗した場合です。 |
| `ENGINE_FAILURE` | ハンドラーが分類されていないエラーをスローした場合です。 |

```ts
/** A native dialog as a test's handler sees it. */
export interface Dialog {
  /** The native dialog kind, independent of its message. */
  readonly type: 'alert' | 'confirm' | 'prompt' | 'beforeunload';
  /** The dialog's text. */
  readonly message: string;
  /** Accepts the dialog once. */
  accept(text?: string): Promise<void>;
  /** Dismisses the dialog once. */
  dismiss(): Promise<void>;
}

export type DialogHandler = 'accept' | 'dismiss' | ((dialog: Dialog) => void | Promise<void>);
```

#### タブ

`target="_blank"` のリンクや `window.open` からアプリが開いたタブは、バックグラウンドで
開きます。アクティブなタブは元のままで、`screen`、`expect`、`browser` のページ
メソッドは引き続きそのタブに作用します。
`waitForPopup` は、トリガーが開いたタブをアクティブにします。アクティブなタブが
閉じると、それを開いたタブが再びアクティブになります。開いたタブもなくなっている
場合は、開いているタブのうち最も最近アクティブだったタブがアクティブになります。

```ts
const popup = await browser.waitForPopup(() =>
  screen.getByRole('button', 'Open verification tab').tap(),
);
const code = await screen.getByText(/^TAB-/).textContent();
await popup.close(); // the opener is active again
await screen.getByRole('textbox', 'Verification code').fill(code);
```

- `waitForPopup(trigger)` はトリガーを実行し、それが開いたタブがアクティブになった
  時点でそのタブで解決されます。待機の開始後にアプリが最初に開いたタブを取るため、
  以前のアクションが開き、今になってページが読み込まれたタブになることもあります。
- `tabs()` は開いているタブを開いた順に返し、1 つのタブには試行全体で同じ
  `BrowserTab` が使われます。タブは最初のページが読み込まれた時点で加わるため、
  1 つのアクションが開いた 2 つのタブは、ページが読み込まれた順に並びます。
  ページを一度も持たないタブは記載されません。ダウンロードへの `target="_blank"`
  リンク、`mailto:` アドレスへのリンク、コンテンツのないレスポンスへのリンクなどです。
- `tab.activate()` は、他のタブを閉じずにタブをアクティブにします。
  `tab.close()` はタブを閉じ、それがアクティブだった場合は次のタブがアクティブになる
  まで待ちます。
- `newTab()` は、同じ Cookie とストレージを持つ同じブラウザコンテキストに空白の
  タブを開き、それをアクティブにします。`goto` で移動してください。
- Chromium では、タブが読み込まれる前に開いた側のタブが閉じたタブも記載されます。
  テストが `surfaceOf(engine)` を通じて開いたページは記載されません。
- スクリーンキャストはアクティブなタブを録画し、切り替わるたびに 1 つのビデオ
  セグメントになります。自ら閉じるタブはセグメントを残しません。録画を保存できる前に
  ページが閉じるためです。プロバイダー自身の録画はすべてのタブを対象にします。

```ts
/** One tab of the browser the attempt drives. */
export interface BrowserTab {
  url(): Promise<string>;
  title(): Promise<string>;
  /** Whether this is the active tab. */
  isActive(): boolean;
  isClosed(): boolean;
  /** Makes this the active tab. */
  activate(): Promise<void>;
  /** Closes the tab; the tab that opened it becomes active when it was. */
  close(): Promise<void>;
}
```

| 例外 | 発生条件 |
| --- | --- |
| `ACTION_FAILED` | `waitForPopup`: 時間内にタブが開かなかった場合です。トリガーが時間内に解決した場合は `no tab opened within <n>ms; the trigger resolved after <m>ms` で失敗し、タブが最初のページをまだ読み込み中だった場合は `the tab the app opened did not load <url> within <n>ms` で失敗します。`activate`: タブが閉じている場合です。 |

#### `waitForDownload`

トリガーを実行し、それが開始するダウンロードを待ちます。

```ts
const file = await browser.waitForDownload(() =>
  screen.getByRole('link', 'Export CSV').tap(),
);
```

- ファイルを `download` アーティファクトとして登録し、相対的な `path`、ランナー側の
  `absolutePath`、`suggestedFilename` を返します。
- 内容を調べるには、ファイル API で `absolutePath` を使います。ホスト型ブラウザでも
  同様です。
- ホスト型ブラウザでは、ファイルはプロバイダーの
  [`downloads`](/browser#downloads-on-the-provider) を通じて戻ってきます。
- 待機時間にはトリガー自体の時間も含まれます。

| 例外 | 発生条件 |
| --- | --- |
| `ACTION_FAILED` | ダウンロードが時間内に完了しなかった場合です。トリガーが時間内に解決したもののダウンロードを開始しなかった場合は、`no download started within <n>ms; the trigger resolved after <m>ms` で失敗します。 |

タイムアウト時にまだ実行中のトリガーは、ステップのタイムアウトで失敗します。
スローしたトリガーは、そのエラーで失敗します。

#### `waitForDownloads`

`waitForDownloads(trigger, { count })` はトリガーを 1 回呼び出し、同じタイムアウトの
もとで、`count` 個のファイルを開始順に返します。それぞれが独立したアーティファクトです。
時間内に開始されたダウンロードが足りない場合、エラーには両方の数が示されます。余分な
ダウンロードは無視されます。

#### `keyboard`

ビューポートレベルのキーボード入力で、フォーカスのある要素が対象です。

```ts
await browser.keyboard.press('Escape');
await browser.keyboard.type('hello');
```

- `type(text)` はプレーンテキストのみを入力し、`Secret` は入力しません。
- ターゲットがある場合は、`locator.press` と `locator.fill` を優先してください。
- 各メソッドの説明は [`Browser`](#browser-interface) にあります。

#### `mouse`

テストコードからのビューポートレベルのポインター入力で、エージェントの観測とは
独立しています。

```ts
await browser.mouse.move(120, 240);
await browser.mouse.down();
await browser.mouse.move(320, 240);
await browser.mouse.up();
```

`wheel` を含む各メソッドの説明は [`Browser`](#browser-interface) にあります。

## ブラウザのインストール

パッケージは `playwright-core` を正確なバージョンに固定しているため、エンジンは常に
テスト済みの Playwright で動作します。Playwright 自体に依存するアプリは、独自の
コピーを保持します。両者がブラウザキャッシュを共有するのは、バージョンが一致する
場合だけです。

ブラウザがない場合は、実行ごとに 1 回、実行の計時が始まる前にダウンロードされます。
CI やコンテナイメージでブラウザのインストールを独立したステップとして行うには、
パッケージのコマンドを実行します。このコマンドは、エンジンが固定している Playwright
用のブラウザをインストールします。

<CodeGroup>
```bash npm
npx @e2e-dev/web install chromium --with-deps
```

```bash pnpm
pnpm exec e2e-web install chromium --with-deps
```

```bash bun
bunx @e2e-dev/web install chromium --with-deps
```
</CodeGroup>

- `chromium`、`firefox`、`webkit` を任意に指定できます。何も指定しない場合は
  `chromium` をインストールします。
- `--with-deps` を指定すると、Linux でブラウザが必要とするシステムライブラリも
  インストールします。
- コマンドはインストーラーの終了コードで終了します。

## セマンティックキャプチャの復旧

セマンティックリーダーがタイムアウトした場合、エージェントの観測は新しいビューポートの
スクリーンショットで復旧できます。

- Playwright は、open と closed の Shadow ルートを含む、到達可能なすべてのフレームで
  新たにセキュアフィールドのマスクスイープを実行します。すべてのマスクのプローブが
  成功する必要があります。
- 観測は、セマンティクスが利用できないことを報告し、以前のノード参照をクリアします。
- 復旧には、操作の予算に残り時間があることと、ランナーの許可が必要です。`act` は
  これを許可します。判定には `vision: true` または `'only'` が必要です。
- マスキングの失敗、キャンセル、深刻なエンジンエラーの場合は、引き続き観測が停止します。

フォールバックが許可されている場合、リーダーは残りの観測予算の 4 分の 1（上限 2 秒）を
スクリーンショット用に確保します。期限は、ページの走査、メタデータと要素の読み戻し、
ネストされたフレームを対象とします。

シリアライズのオーバーヘッドを減らすため、セマンティックのメタデータは 1 つの JSON
文字列として Playwright の接続を渡ります。リーダーが走査した要素はドキュメントごとに
1 つのページ内配列に保持され、アクションはノードに最初にアクセスするときに、その配列から
ノードのハンドルを作成します。参照は、後でその位置にあるものではなく、走査で読み取った
要素を指します。`JSON.stringify` を置き換えたり、オブジェクトや配列のプロトタイプに
`toJSON` メソッドを追加したりするページでは、構造化転送が使われます。クリーンアップは
停止したプロトコルの応答を待ちません。放棄されたリーダーは、ノード ID を再利用したり、
より新しい観測の上に参照を公開したりできません。

## surfaceOf

`web()` ハンドルのライブな Playwright サーフェスを返します。ページを自ら駆動する
[カスタムエグゼキューター](/executors#driving-the-page-yourself)向けです。

```ts
import { web, surfaceOf } from '@e2e-dev/web';

const engine = web();
const live = surfaceOf(engine);   // PlaywrightLiveSurface | undefined
live!.page();                     // the Page of the current attempt
live!.context();                  // its BrowserContext
```

- 別のパッケージのハンドルに対しては `undefined` を返します。
- Playwright を直接呼び出しても、ステップとして記録されません。
- [CDP の復旧](#recovering-a-cdp-transport)の後は、アクセサーを読み直してください。

| 例外 | 発生条件 |
| --- | --- |
| `INVALID_STATE` | アクティブな試行の外でアクセサーを呼び出した場合です。 |

## 型

パッケージは、設定ヘルパーやフィクスチャに型を付けるために次の型をエクスポートします。
`WebOptions`、`WebMedia`、`WebScreencastOptions`、`WebConnectOptions`、
`WebBasicAuth`、`WebInitScript`、`BrowserName`、`BrowserProvider`、
`BrowserProviderScope`、`BrowserRequest`、`BrowserLease`、
`BrowserReleaseContext`、`BrowserProviderDownloads`、
`BrowserDownloadContext`、`PlaywrightLiveSurface`、`Browser`、`FrameScreen`、
`BrowserExpectation`、`WebRoute`、`RouteFulfillResponse`、
`RouteContinueOverrides`、`WebResponse`、`Cookie`、`CookieFields`、
`CookieFilter`、`Dialog`、`DialogHandler` です。

ランタイムのエクスポートは、`web`、[`surfaceOf`](#surfaceof)、そして `browser`
フィクスチャで型付けされた `test`、`describe`、`beforeEach`、`afterEach`、
`beforeAll`、`afterAll` です。

### `WebOptions`

```ts
/**
 * Options of the browser engine: how it drives the app. The app itself
 * (its `url`, `environment`, `identity`, and the command that starts it) is
 * the target's `app`.
 */
export interface WebOptions {
  /**
   * Browser to launch, `chromium` by default. A `BrowserProvider` leases
   * hosted browsers instead: one per worker slot at `prepare`, or one per
   * attempt, each attached to over CDP and released when its scope ends. A
   * provider implies chromium and excludes `connect`.
   */
  readonly browser?: BrowserName | BrowserProvider;
  /**
   * Initial viewport of every attempt's page; default 1280 by 720. `null`
   * emulates no size: the page fills the browser window, whatever size the
   * window has (a hosted browser's live view, a headed run), and
   * `browser.setViewport` still fixes one for the rest of the attempt.
   */
  readonly viewport?: ViewportSize | null;
  /**
   * How the engine's own screencast records an attempt that records video.
   * A browser provider that records (`BrowserProvider.record`) records in
   * its place, and ignores these. Which attempts record is the config's
   * `video`, not an engine option.
   */
  readonly screencast?: WebScreencastOptions;
  /**
   * Attach to a remote browser over CDP instead of launching locally. Requires
   * the chromium browser (the default). Wired by a hosted-browser engine.
   */
  readonly connect?: WebConnectOptions;
  /**
   * Headers added to every request that starts at the app's origin (the
   * scheme, host, and port of `app.url`) or one in `credentialOrigins`.
   * Useful for preview-protection tokens. A request that starts at another
   * origin goes without them; a redirect keeps them, to any origin.
   * Names are case-insensitive and replace existing headers of the same name.
   * This enables request routing, disables the browser's HTTP cache, and
   * blocks service workers.
   */
  readonly headers?: Readonly<Record<string, string>>;
  /**
   * HTTP basic authentication. The browser answers a `401` challenge from the
   * app's origin, or one in `credentialOrigins`, with these credentials.
   */
  readonly basicAuth?: WebBasicAuth;
  /**
   * More origins that receive `headers` and `basicAuth`, such as
   * `https://api.example.com`; requires `headers` or `basicAuth`.
   */
  readonly credentialOrigins?: readonly string[];
  /**
   * The attribute that carries an element's test id: what the `testId` query
   * (`screen.getByTestId`) resolves and what `SemanticNode.testId` reports.
   * Defaults to `data-testid`.
   */
  readonly testIdAttribute?: string;
  /**
   * The `User-Agent` every attempt's context sends and `navigator.userAgent`
   * reports, for an app that switches into a test mode on a marker in the
   * agent string. Defaults to the browser's own. A `user-agent` entry in
   * `headers` beside it is `INVALID_CONFIG`, and so is a persistent context
   * (`connect.reconnectEndpoint`, or a provider with `scope: 'attempt'`).
   */
  readonly userAgent?: string;
  /**
   * The locale every attempt's context runs in, a BCP 47 tag such as
   * `de-DE`: what `navigator.language`, `Intl` formatting, and the
   * `Accept-Language` header report. Defaults to the browser's own. An
   * `accept-language` entry in `headers` beside it is `INVALID_CONFIG`, and
   * so is a persistent context.
   */
  readonly locale?: string;
  /**
   * The IANA time zone every attempt's context runs in, such as
   * `Europe/Berlin`: what `Date` and `Intl` resolve local time against.
   * Defaults to the machine's. A persistent context is `INVALID_CONFIG`.
   */
  readonly timezoneId?: string;
  /** The `prefers-color-scheme` every page reports. See [Media emulation](#media-emulation). */
  readonly colorScheme?: WebMedia['colorScheme'];
  /** The `prefers-reduced-motion` every page reports. See [Media emulation](#media-emulation). */
  readonly reducedMotion?: WebMedia['reducedMotion'];
  /** Scripts every document runs before the page's own. See [Init scripts](#init-scripts). */
  readonly initScripts?: readonly WebInitScript[];
}
```

### `Browser` インターフェース

```ts
/**
 * The browser the attempt drives, showing one active tab. Navigation, reads,
 * `locator`, `frameLocator`, `evaluate`, `waitForResponse`, `waitForDownload`,
 * the keyboard and mouse, `expect(browser)`, and `screen` act on the active
 * tab; cookies, routes, and dialog handlers cover the whole browser, every
 * tab included. A tab the app opens (a `target="_blank"` link,
 * `window.open`) joins `tabs()` but does not become active on its own:
 * `waitForPopup` makes the tab its trigger opens active, and `activate`
 * any other. When the active tab closes, the tab that opened it is active
 * again.
 */
export interface Browser extends Expectable<BrowserExpectation> {
  /** Navigates to an allowed URL. */
  goto(
    url: string,
    options?: {
      waitUntil?: 'load' | 'domcontentloaded' | 'networkidle';
      timeout?: number;
    },
  ): Promise<void>;
  /** Reloads the current document. */
  reload(options?: ActionOptions): Promise<void>;
  /** Navigates browser history back once. */
  back(options?: ActionOptions): Promise<void>;
  /** Navigates browser history forward once. */
  forward(options?: ActionOptions): Promise<void>;
  /** Returns the current URL. */
  url(): Promise<string>;
  /** Returns the current title. */
  title(): Promise<string>;
  /** Waits for the current URL to match. */
  waitForURL(url: string | RegExp, options?: { timeout?: number }): Promise<void>;
  /** Creates a web-only CSS or XPath locator. */
  locator(selector: string): Locator;
  /** Creates a screen query scope inside one iframe. */
  frameLocator(selector: string): FrameScreen;
  /** Evaluates trusted test code in the page: a function, or a string expression whose value is returned, called first if it is a function. */
  evaluate<T extends JsonValue>(fn: string | (() => T | Promise<T>)): Promise<T>;
  /** Evaluates trusted test code with one required JSON-safe argument. */
  evaluate<T extends JsonValue, Arg extends JsonValue>(
    fn: string | ((arg: Arg) => T | Promise<T>),
    arg: Arg,
  ): Promise<T>;
  /** Adds a script every document runs before the page's own, from the next navigation on. */
  addInitScript(script: string | { path: string } | (() => unknown)): Promise<void>;
  /** Adds an init script function called with one JSON argument. */
  addInitScript<Arg extends JsonValue>(script: (arg: Arg) => unknown, arg: Arg): Promise<void>;
  /** Adds an attempt-scoped network route. */
  route(
    pattern: string | RegExp,
    handler: (route: WebRoute) => void | Promise<void>,
  ): Promise<void>;
  /** Removes matching attempt-scoped routes. */
  unroute(pattern: string | RegExp): Promise<void>;
  /** Removes all routes registered by this browser fixture, preserving the configured headers. */
  unrouteAll(): Promise<void>;
  /** Waits for a matching response. */
  waitForResponse(
    pattern: string | RegExp,
    options?: { timeout?: number },
  ): Promise<WebResponse>;
  /** Returns cookies visible to the current context. */
  cookies(): Promise<Cookie[]>;
  /** Sets cookies after URL validation. */
  setCookies(cookies: readonly Cookie[]): Promise<void>;
  /** Removes matching cookies only; without filters removes every cookie, preserving other storage. */
  clearCookies(options?: CookieFilter): Promise<void>;
  /** Sets the viewport size. */
  setViewport(size: { width: number; height: number }): Promise<void>;
  /** Emulates CSS media features on every open tab and every tab opened after them. */
  emulateMedia(media: WebMedia): Promise<void>;
  /** Registers an attempt-scoped dialog handler and returns an unsubscribe function. */
  onDialog(handler: DialogHandler): Promise<() => Promise<void>>;
  /** Returns the open tabs, in the order they opened. */
  tabs(): readonly BrowserTab[];
  /**
   * Runs a trigger and waits for the tab it opens, then resolves with that
   * tab once it is the active tab. The wait takes the first tab the app
   * opens after it starts, which can be one an earlier action opened whose
   * page loaded only now. Rejects with `ACTION_FAILED` when no tab opens
   * within the timeout, naming the page when a tab was still loading it.
   */
  waitForPopup(trigger: () => Promise<void>, options?: { timeout?: number }): Promise<BrowserTab>;
  /** Opens a blank tab in the same browser context, sharing its cookies and storage, and makes it the active tab. */
  newTab(): Promise<BrowserTab>;
  /** Runs a trigger and waits for its download. */
  waitForDownload(
    trigger: () => Promise<void>,
    options?: { timeout?: number },
  ): Promise<{ path: string; absolutePath: string; suggestedFilename: string }>;
  /** Runs one trigger and waits for the requested number of completed downloads. */
  waitForDownloads(
    trigger: () => Promise<void>,
    options: { count: number; timeout?: number },
  ): Promise<readonly { path: string; absolutePath: string; suggestedFilename: string }[]>;
  /** Viewport-level keyboard, for whatever has focus. */
  readonly keyboard: {
    /** Sends one key. */
    press(key: string): Promise<void>;
    /** Holds one key until up; repeated down calls send a repeat event. */
    down(key: string): Promise<void>;
    /** Releases a held key. */
    up(key: string): Promise<void>;
    /** Types plain text. */
    type(text: string): Promise<void>;
  };
  /**
   * Direct pointer input from test code, independent of agent observations.
   * After CDP recovery, test code can read current geometry with `evaluate`
   * before starting a pointer sequence.
   */
  readonly mouse: {
    /** Moves the pointer. */
    move(x: number, y: number): Promise<void>;
    /** Scrolls the pointer wheel. */
    wheel(deltaX: number, deltaY: number): Promise<void>;
    /** Presses the primary pointer button. */
    down(): Promise<void>;
    /** Releases the primary pointer button. */
    up(): Promise<void>;
  };
}
```
