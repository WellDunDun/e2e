title: "@e2e-dev/core"

---

`@e2e-dev/core` は、テストランナーを介さずにブラウザやデバイスを操作する
プログラムの API です。`launch` はホストを返し、ホストはセッションを開き、
`createAgent` はセッションの上にエージェントを置きます。それぞれの使い方は
[ガイド](/core)で紹介しています。

```ts title="prices.ts"
import { launch } from '@e2e-dev/core';
import { web } from '@e2e-dev/web/engine';

await using shop = await launch(web(), { app: { url: 'https://shop.example.com' } });
await using session = await shop.newSession();
await session.app.open('/products/A-1001');
console.log(await session.screen.getByTestId('sale-price').textContent());
```

### 起動

| 関数 | 戻り値 |
| --- | --- |
| [`launch`](#launch) | `Promise<Host>` |

#### `launch`

エンジンを準備し、その上でセッションを開くホストを返します。`web()` の初回の
launch ではブラウザをダウンロードします。

```ts
const shop = await launch(web(), {
  app: { url: 'https://shop.example.com' },
  timeout: 10_000,
  artifactsDir: 'artifacts',
});
```

| オプション | 型 | デフォルト |
| --- | --- | --- |
| [`app`](#app) | `LaunchApp` | - |
| `secrets` | `Record<string, string>` | - |
| `headed` | `boolean` | `false` |
| [`timeout`](#timeout) | `number` | 操作ごと |
| `signal` | `AbortSignal` | - |
| `handleSignals` | `boolean` | `true` |
| `artifactsDir` | `string` | 一時ディレクトリ |
| `cwd` | `string` | `process.cwd()` |
| `env` | `NodeJS.ProcessEnv` | `process.env` |
| `onNotice` | `(message: string) => void` | - |

- `secrets`: 名前ごとの値で、それぞれ 6 文字以上です。
  [シークレットを渡す](/core#pass-secrets)を参照してください。
- `headed`: ブラウザウィンドウを表示します。デバイスでは無視されます。
- `signal`: launch と、ホスト上のすべてのセッションと操作をキャンセルします。
- `handleSignals`: SIGINT、SIGTERM、SIGHUP を受け取るとホストを閉じ、その後
  シグナルによってプログラムを終了させます。ただし、プログラム自身がそのシグナルを
  待ち受けている場合は除きます。
- `artifactsDir`: スクリーンショット、ダウンロード、録画の保存先で、`cwd` から
  解決されます。デフォルトのディレクトリはホストが閉じると削除されます。
- `cwd`: アップロードのパス、`artifactsDir`、エージェントのキャッシュディレクトリの
  解決の起点です。
- `onNotice`: ブラウザのダウンロードやデバイスのリースなど、操作の外で起きる
  進捗です。

| スローされるエラー | 条件 |
| --- | --- |
| `INVALID_ARGUMENT` | 第 1 引数がエンジンではない、またはオプションや `app` のキーが不明です。 |
| `INVALID_CONFIG` | エンジンがアプリを拒否しました。`app.url` のない `web()`、`app.bundleId` も `app.appPath` もない `mobile()` です。 |
| `WORKER_PROTOCOL` | 別のホストがこのエンジンインスタンスを所有しています。ファクトリーをもう一度呼び出してください: `launch(web())`。 |

<a id="app" />

##### `app`

`app.open()` がブラウザで開くもの、またはデバイスで起動するものです。

| フィールド | 対象 | 意味 |
| --- | --- | --- |
| `url` | `web()` | アプリの URL です。`app.open(path)` はこれを基準に解決されます。 |
| `bundleId` | `mobile()` | 起動するインストール済みのアプリです。 |
| `appPath` | `mobile()` | プログラムが実行対象とするアプリのビルドで、`.app` または `.apk` です。[設定](/reference/config#apppath)を参照してください。 |
| `linkBase` | `mobile()` | `app.open(path)` がパスを結合し、リンクとして開く基準です。[設定](/reference/config#linkbase)を参照してください。 |
| `identity` | 両方 | 保存した状態と録画で使うアプリの名前です。デフォルト: URL またはバンドル ID。 |
| `launchArguments` | `mobile()` | アプリの起動時に渡す引数です。 |
| `permissions` | 両方 | 許可または拒否する権限です。 |

<a id="timeout" />

##### `timeout`

1 回の操作のデフォルトのタイムアウトで、単位はミリ秒です。指定しない場合:

| 操作 | デフォルト |
| --- | --- |
| アクション、待機、読み取り | 30000 |
| `app.open()`, `app.restart()`, `app.clearState()` | 120000 |
| エージェントのステップ | 120000、または呼び出し自身の `timeout` |

`timeout` は最初の 2 行を設定します。セッションの期限はありません。

### ホスト

| メンバー | 戻り値 |
| --- | --- |
| `platform` | `string` |
| [`newSession`](#newsession) | `Promise<Session>` |
| [`secret`](#secret) | `Secret` |
| [`close`](#close) | `Promise<void>` |

`platform` は `web`、`ios`、`android`、またはカスタムエンジン独自のラベルです。

#### `newSession`

セッションを開きます。1 つの分離されたブラウザコンテキスト、またはデバイス上の
アプリです。ホストが同時に保持できるセッションは 1 つです。

```ts
const session = await shop.newSession({ state, signal: AbortSignal.timeout(60_000) });
```

| オプション | 型 | デフォルト |
| --- | --- | --- |
| `state` | [`SessionState`](#sessionstate) | - |
| `signal` | `AbortSignal` | - |

| スローされるエラー | 条件 |
| --- | --- |
| `WORKER_PROTOCOL` | ホストでセッションが開いている、またはホストが閉じています。 |
| `SESSION_MISMATCH` | `state` が別のエンジン、プラットフォーム、またはアプリで保存されました。 |
| `SESSION_EXPIRED` | `state` の有効期限が切れています。 |

#### `secret`

`launch` に渡したシークレットのハンドルを返します。`fill` やエージェントの
パラメーターで使います。不明な名前を指定すると `SECRET_UNAVAILABLE` をスローします。

```ts
await session.screen.getByLabel('Password').fill(shop.secret('SHOP_PASSWORD'));
```

#### `close`

開いているセッションを閉じ、次にエンジンを閉じます。2 回目の呼び出しでは何も
しません。ホストは破棄可能でもあり、`await using` で閉じられます。クリーンアップが
失敗した場合は、失敗をまとめた `AggregateError` をスローします。

### セッション

| メンバー | 戻り値 |
| --- | --- |
| `screen` | [`Screen`](/reference/screen) |
| `app` | [`App`](/reference/app) |
| `platform` | `string` |
| `browser` | [`Browser`](/reference/web)、`web()` の場合 |
| `device` | [`Device`](/reference/mobile)、`mobile()` の場合 |
| [`saveState`](#savestate) | `Promise<SessionState>` |
| [`setDefaultTimeout`](#setdefaulttimeout) | `void` |
| `close` | `Promise<void>` |

`close` は `await using` と同じようにセッションを終了します。その後は、すべての
操作が `CANCELLED` で失敗します。

#### `saveState`

セッションの Cookie とストレージをメモリーに取り込みます。`mobile()` のように
取り込む状態がないエンジンでは `UNSUPPORTED_CAPABILITY` をスローします。

```ts
const state = await session.saveState();
```

#### `setDefaultTimeout`

これ以降に開始する操作のデフォルトのタイムアウトをミリ秒で設定します。対象は
アクション、待機、読み取り、アプリのオープンと再起動です。

```ts
session.setDefaultTimeout(5_000);
```

### SessionState

| メンバー | 戻り値 |
| --- | --- |
| `engine` | `string` |
| `platform` | `string` |
| [`export`](#export) | `Promise<Uint8Array>` |
| [`SessionState.import`](#sessionstate-import) | `Promise<SessionState>` |

#### `export`

32 バイトの鍵 (AES-256-GCM) で状態を暗号化し、ディスクに書き込めるバイト列に
します。平文でのエクスポートはありません。

```ts
const bytes = await state.export({ key });
```

バイト列には、エンジン、プラットフォーム、シークレットの名前が平文で含まれます。
Cookie、ストレージ、シークレットの値は暗号化されます。

#### `SessionState.import`

`export` が書き出したバイト列を復号します。

```ts
const state = await SessionState.import(bytes, { key });
```

| スローされるエラー | 条件 |
| --- | --- |
| `SESSION_INVALID` | 別の鍵、変更されたバイト、または `export` が書き出したものではないバイト列です。 |
| `SESSION_EXPIRED` | 状態の有効期限が切れています。 |
| `INVALID_ARGUMENT` | 鍵が 32 バイトではありません。 |

### エージェント

| 関数 | 戻り値 |
| --- | --- |
| [`createAgent`](#createagent) | エージェント |

#### `createAgent`

1 つのセッションの上にエージェントを作成します。`assert`、`waitFor`、`extract` は
[agent フィクスチャ](/reference/agent)のものと同じです。`act` は 1 点だけ異なり、
`cache` を指定すると `cacheKey` を受け取ります。

```ts
const agent = createAgent(session, {
  model: gateway('anthropic/claude-sonnet-5-5'),
  cache: { dir: '.shop-bot/cache' },
});
const step = await agent.act('Add the item to the cart', { cacheKey: 'add-to-cart' });
```

| オプション | 型 | デフォルト |
| --- | --- | --- |
| `model`、`judge`、`context` など | [`agents` のエントリー](/reference/config#agents) | - |
| [`cache`](#cache) | `AgentCacheOptions` | キャッシュなし |

<a id="cache" />

##### `cache`

| フィールド | 型 | デフォルト |
| --- | --- | --- |
| `dir` | `string` | `.e2e/cache` |
| `mode` | `'read-write' \| 'read-only'` | `'read-write'` |
| `strict` | `boolean` | `false` |
| `store` | [`CacheStore`](/cache) | ファイルストア |

`cache` を指定した場合、各 `act` には `{ cacheKey: '<name>' }` を渡すか、ライブで
実行するには `{ cache: false }` を渡します。記録がいつ保存されるかは
[記録したステップをリプレイする](/core#replay-recorded-steps)で説明しています。
