`app` フィクスチャは、テスト対象のアプリを開き、再起動し、リセットします。また、
スクリーンショットと録画を取得します。すべてのターゲットで使えます。エンジンが実行できないメソッドは
`UNSUPPORTED_CAPABILITY` で失敗します。

```ts title="tests/billing.e2e.ts"
import { expect, test } from 'e2e';

test('billing page', async ({ app, screen }) => {
  await app.open('/settings/billing');
  await expect(screen.getByRole('heading', { name: 'Billing' })).toBeVisible();
  await app.screenshot('billing');
});
```

## リファレンス

| メンバー | 戻り値 |
| --- | --- |
| [`baseUrl`](#baseurl) | `string \| undefined` |
| [`open`](#open) | `Promise<void>` |
| [`restart`](#restart) | `Promise<void>` |
| [`clearState`](#clearstate) | `Promise<void>` |
| [`back`](#back) | `Promise<void>` |
| [`screenshot`](#screenshot) | `Promise<string>` |
| [`startRecording`](#startrecording) | `Promise<void>` |
| [`stopRecording`](#stoprecording) | `Promise<[RecordedVideo, ...RecordedVideo[]]>` |

`open`、`restart`、`clearState` は `timeout` で制限されます。それ以外は
`actionTimeout` で制限されます。どちらも[設定](/reference/config)から取得され、
`timeout` のデフォルトは 120000 ms、`actionTimeout` のデフォルトは 30000 ms です。
テストの残りのタイムアウトが両方の上限になります。`app` のメソッドは
呼び出しごとのタイムアウトオプションを受け取りません。

### `baseUrl`

ターゲットのアプリの、解決済みのベース URL です。

```ts
const health = await fetch(`${app.baseUrl}/api/health`);
```

- 末尾のスラッシュは付かないため、`${app.baseUrl}/path` はスラッシュ 1 つで
  結合されます。
- `app.url` がポート `0` を宣言している場合、`baseUrl` には実行時に割り当てられた
  ポートが入ります。
- `app.url` を宣言していないターゲットでは `undefined` です。`@e2e-dev/web` の
  `test` では `string` 型になります。`web()` ターゲットは必ず `app.url` を
  宣言するためです。

### `open`

アプリを開きます。宣言された URL、それを基準とした相対パス、または任意の絶対
`http(s)` URL を指定できます。

```ts
await app.open(); // the target's app.url
await app.open('/settings/billing'); // a path relative to app.url
await app.open('https://example.com/login'); // any http(s) URL
```

URL を持たないデバイスターゲットでは、`open()` は固定されたアプリを新しく起動します。
ターゲットが [`app.linkBase`](/reference/config#linkbase) を宣言している場合、
パスはアプリ内のリンクとして開かれ、宣言していない場合は `APP_URL_REQUIRED` に
なります。リンクベースがある場合、絶対リンクはカスタムアプリスキームも含めて
指定されたとおりに開かれます。

| スローされるエラー | 条件 |
| --- | --- |
| `APP_URL_REQUIRED` | `app.url` を宣言していない (デバイスでは `app.linkBase` を宣言していない) ターゲットでパスを指定しました。 |
| `POLICY_DENIED` | スキームが `http:` でも `https:` でもない URL です。`about:blank` は許可されます。`app.linkBase` のあるデバイスでは、スキームが `file:`、`data:`、`javascript:`、`view-source:`、`blob:`、`filesystem:` のリンクです。 |
| `APP_UNREACHABLE` | アプリの URL に到達できませんでした。 |
| `ACTION_FAILED` | 操作が失敗したか、タイムアウトしました。 |
| `UNSUPPORTED_CAPABILITY` | URL のあるターゲットで `session.open` がない、または URL のないターゲットで `session.restart` がありません。`app.bundleId` のないデバイスでは、ターゲットのビルドがまだインストールされていない場合も含みます ([mobile](/reference/mobile#the-app-under-test))。 |

### `restart`

永続化された状態を保ったまま、実行コンテキストを作り直します。その後、ターゲットが
ベース URL を宣言している場合は、そのベース URL でアプリを開き直します。

```ts
await app.restart();
```

| スローされるエラー | 条件 |
| --- | --- |
| `ACTION_FAILED`, `ENGINE_FAILURE` | 操作またはエンジンが失敗しました。 |
| `UNSUPPORTED_CAPABILITY` | `session.restart` がない、または `app.bundleId` のないデバイスでビルドがまだインストールされていません。 |

### `clearState`

永続化されたクライアントの状態を消去し、実行コンテキストを作り直します。その後、
ターゲットがベース URL を宣言している場合は、そのベース URL でアプリを開き直します。

```ts
test.beforeEach(async ({ app }) => {
  await app.clearState();
});
```

| スローされるエラー | 条件 |
| --- | --- |
| `ACTION_FAILED`, `ENGINE_FAILURE` | 操作またはエンジンが失敗しました。 |
| `UNSUPPORTED_CAPABILITY` | `session.reset` がない、または `app.bundleId` のないデバイスでビルドがまだインストールされていません。 |

<Warning>
シリアルグループ内で `clearState` を使うと、グループが依存している共有状態が
破棄されます。代わりに、通常のグループの `beforeEach` で使ってください。
</Warning>

### `back`

1 回戻ります。

```ts
await app.back();
```

| スローされるエラー | 条件 |
| --- | --- |
| `APP_NOT_OPEN` | `app.open()` が実行されていない、またはエンジンが無効な状態を報告しました。 |
| `ACTION_FAILED` | 操作が失敗したか、タイムアウトしました。 |
| `UNSUPPORTED_CAPABILITY` | `session.back` がありません。 |

### `screenshot`

秘匿処理を施した証拠用のスクリーンショットを撮影し、そのパスを返します。

```ts
const shot = await app.screenshot('after-checkout');
```

- ファイルは `screenshots/` 配下の試行のアーティファクトです。返されるパスは
  絶対パスです。レポートにはアーティファクトのルートからの相対パスが記録されます。
- `list` レポーターのサマリーは、`Screenshots` 行に最大 10 個のファイルを表示し、
  残りは件数で示します。
- `label` はステップの名前になり、ファイル名にも含まれます。
- ページの遷移中に撮影したスクリーンショットには、表示中のドキュメントが写ります。

| スローされるエラー | 条件 |
| --- | --- |
| `UNSUPPORTED_CAPABILITY` | エンジンがスクリーンショットを撮影できません。 |
| `ENGINE_FAILURE` | 撮影に失敗しました。 |

<Note>
スクリーンショットでマスクされるのはセキュアなフィールドだけで、`Secret` で入力した
後も同様です。アプリがそれ以外の場所に表示するシークレットは画像に写ります。
[シークレット入力後のスクリーンショット](/reference/security#screenshots-after-a-secret-fill)を参照してください。
</Note>

### `startRecording`

`stopRecording` が呼ばれるまで、画面の録画を開始します。

```ts
test('the dialog slides in', { video: 'off' }, async ({ app, screen }) => {
  await app.open();
  await app.startRecording({ name: 'dialog' });
  await screen.getByRole('button', 'Open').tap();
  await expect(screen.getByRole('dialog')).toBeVisible();
  const [video] = await app.stopRecording();
});
```

- 録画は一度に 1 つだけです。エンジンのレコーダーは 1 つなので、テストに
  `video: 'off'` を設定してください。テストの [video](/reference/config#video) が
  録画している間は、開始に失敗します。これには `--video`、`retain-on-failure`、
  `on-first-retry` が録画するリトライも含まれます。
- テストの終了時にまだ実行中の録画は停止され、保持されます。
- テストの動画と同様に、録画では何もマスクされません。

| スローされるエラー | 条件 |
| --- | --- |
| `UNSUPPORTED_CAPABILITY` | テストの動画が録画中である、またはエンジンが動画を録画できません。 |
| `INVALID_ARGUMENT` | 別の録画が実行中です。 |

### `stopRecording`

録画を停止し、その動画を再生順に返します。

```ts
const [video] = await app.stopRecording();
if ('path' in video) console.log(video.path);
```

- 動画は試行の `recordings/` 配下にある `001-<name>.<ext>` という名前のファイル
  (`path`、絶対パス) か、ホスト型ブラウザやデバイスが録画を保持する場合は `url` です。
- 動画は 1 つです。ただし、Web で録画中にページが置き換えられた場合
  (`app.restart()`、`app.clearState()`) は、ページごとに 1 つになります。
- ステップはトレース内で各動画にリンクします。

| スローされるエラー | 条件 |
| --- | --- |
| `INVALID_ARGUMENT` | 実行中の録画がありません。 |
| `ENGINE_FAILURE` | エンジンが動画を書き出しませんでした。 |

## 型

```ts
export interface App {
  /**
   * The resolved base URL of the target's app, with the port the run
   * allocated when `app.url` declared port 0 and no trailing slash, so
   * `${app.baseUrl}/api/users` joins with one slash; undefined for a target
   * that declares no `app.url`.
   */
  readonly baseUrl: string | undefined;
  /**
   * Opens the app: the declared URL, a path relative to it, or any absolute
   * http(s) URL. On a device target, which has no URL, it launches the pinned
   * app fresh; a path opens as a link in it when the target declares
   * `app.linkBase`.
   */
  open(path?: string): Promise<void>;
  /**
   * Recreates the execution context while preserving persisted state, then
   * reopens the app at its base URL when the target declares one.
   */
  restart(): Promise<void>;
  /**
   * Clears persisted client state, recreates the execution context, then
   * reopens the app at its base URL when the target declares one.
   */
  clearState(): Promise<void>;
  /** Navigates back once. */
  back(): Promise<void>;
  /** Captures a redacted evidence screenshot and returns its absolute path. */
  screenshot(label?: string): Promise<string>;
  /**
   * Starts recording the screen, until `stopRecording`. One recording at a
   * time, and none while the test's `video` records: set `{ video: 'off' }`
   * on the test.
   */
  startRecording(options?: RecordingOptions): Promise<void>;
  /**
   * Stops the recording and returns its videos in play order: one, or on the
   * web one per page when the page was replaced while it recorded.
   */
  stopRecording(): Promise<readonly [RecordedVideo, ...RecordedVideo[]]>;
}

/** How `app.startRecording` names its file. */
export interface RecordingOptions {
  /** File name stem, `recordings/001-<name>.<ext>`; defaults to `recording`. */
  readonly name?: string;
}

/** One video `app.stopRecording` returns: a file, or a link to a recording a hosted service keeps. */
export type RecordedVideo = RecordedVideoFile | RecordedVideoLink;

/** A video file under the attempt's `recordings/` directory. */
export interface RecordedVideoFile {
  /** Absolute path of the file. */
  readonly path: string;
  /** When it started recording, as an ISO timestamp. */
  readonly startedAt: string;
}

/** A recording a hosted browser or device service keeps, by URL. */
export interface RecordedVideoLink {
  /** `http(s)` URL of the recording. */
  readonly url: string;
  /** Media type of what the URL serves: `video/mp4`, or `text/html` for a player page. */
  readonly mediaType: string;
  /** When it started recording, as an ISO timestamp. */
  readonly startedAt: string;
}
```
