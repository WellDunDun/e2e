`@e2e-dev/e2b` は、ターゲットを [E2B](https://e2b.dev) のサンドボックスで実行します。
Android 16 は [デバイスプロバイダー](/mobile#hosted-devices) である `e2b()` で、
Chromium は `@e2e-dev/e2b/web` の [ブラウザプロバイダー](/browser#hosted-browsers) である
`e2bBrowsers()` で実行します。テストはそのままで構いません。

## 認証する

e2e を起動する環境に `E2B_API_KEY` を設定します。CI ではシークレットとして保存してください。
キーは [E2B のダッシュボード](https://e2b.dev/dashboard) からコピーします。
専用の E2B クラスターを使う場合は、`E2B_DOMAIN` も設定します。キーがないと、
プロバイダーは `INVALID_CONFIG` で失敗します。

## Android ターゲットを実行する

各ワーカーは独自の Android サンドボックスを受け取り、約 15〜45 秒で `.apk` がインストールされた状態で
準備が整います。プロバイダーは `device.installApp()` と同様に agent-device を通じて `.apk` を
インストールし、実行の終了時にサンドボックスを削除します。

<Tip>
e2e を実行するマシンに、Android SDK、エミュレーター、`adb` は必要ありません。
</Tip>

モバイルエンジンと一緒にインテグレーションをインストールします。

<CodeGroup>
```bash npm
npm install --save-dev e2e @e2e-dev/mobile @e2e-dev/e2b e2b
```

```bash pnpm
pnpm add -D e2e @e2e-dev/mobile @e2e-dev/e2b e2b
```

```bash bun
bun add -d e2e @e2e-dev/mobile @e2e-dev/e2b e2b
```
</CodeGroup>

ターゲットの `device` を `e2b()` に設定します。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';
import { e2b } from '@e2e-dev/e2b';

export default {
  targets: [
    {
      name: 'android',
      engine: mobile({ platform: 'android', device: e2b() }),
      app: { bundleId: 'com.example.app', appPath: 'build/app-debug.apk' },
    },
  ],
  workers: 4,
} satisfies E2EConfig;
```

`bundleId` は省略可能です。省略すると、`app.open()` は agent-device が `.apk` について
報告するパッケージを開きます。

## ブラウザで Web ターゲットを実行する

ローカル実行と同様に、各ワーカーは独自の Chromium サンドボックスを受け取り、すべての試行は
その中で新しいブラウザコンテキストを受け取ります。`scope: 'attempt'` を指定すると、
代わりにすべての試行が新しいサンドボックスを受け取ります
（[このスコープの制限](/browser#pick-a-lease-scope)）。

Web エンジンと一緒にインテグレーションをインストールします。

<CodeGroup>
```bash npm
npm install --save-dev e2e @e2e-dev/web @e2e-dev/e2b e2b
```

```bash pnpm
pnpm add -D e2e @e2e-dev/web @e2e-dev/e2b e2b
```

```bash bun
bun add -d e2e @e2e-dev/web @e2e-dev/e2b e2b
```
</CodeGroup>

Playwright のイメージから、ブラウザのテンプレートを 1 回だけビルドします。`@e2e-dev/web` が使う
Playwright バージョンのイメージタグを使い、次のようにテンプレートに 4 GB のメモリを割り当てます。

```ts title="build-template.ts"
import { Template, defaultBuildLogger } from 'e2b';

const template = Template().fromImage('mcr.microsoft.com/playwright:v1.65.1-noble');
await Template.build(template, 'e2e-chromium', {
  cpuCount: 4,
  memoryMB: 4096,
  onBuildLogs: defaultBuildLogger(),
});
```

次に、ターゲットの `browser` を `e2bBrowsers()` に設定します。テンプレートに別の名前を付けた場合は、
その名前を `template` として渡します。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { e2bBrowsers } from '@e2e-dev/e2b/web';

export default {
  targets: [
    {
      name: 'e2b-web',
      engine: web({ browser: e2bBrowsers() }),
      app: { url: 'https://staging.example.com' },
    },
  ],
  workers: 4,
} satisfies E2EConfig;
```

ブラウザは E2B のクラウドで動作するため、`app.url` は `localhost` からだけでなく、
インターネットからアクセスできる必要があります。

## Android のオプション

| オプション      | デフォルト        | 意味 |
| ----------- | -------------- | ------- |
| `template`  | `'android-16'` | Android を起動するサンドボックスのテンプレート。 |
| `timeoutMs` | `3600000`（1 時間） | サンドボックスの存続時間。この時間が過ぎると、実行がまだ使用中でも E2B はサンドボックスを終了します。 |

## ブラウザのオプション

| オプション      | デフォルト          | 意味 |
| ----------- | ---------------- | ------- |
| `template`  | `'e2e-chromium'` | Playwright の Chromium を含むサンドボックスのテンプレート。 |
| `scope`     | `'worker'`       | `'worker'`: 実行の間、ワーカースロットごとに 1 つのサンドボックス。`'attempt'`: 試行ごとに新しいサンドボックス。 |
| `timeoutMs` | `3600000`（1 時間） | サンドボックスの存続時間。この時間が過ぎると、実行がまだ使用中でも E2B はサンドボックスを終了します。 |

不明なオプションや無効な値があると、設定の読み込み時に `INVALID_CONFIG` で失敗します。

## サンドボックスを非公開に保つ仕組み

サンドボックスは公開トラフィックを拒否します。プロバイダーは、E2B のアクセストークンを付加する
`127.0.0.1` 上のトンネルを通じて各サンドボックスにアクセスします。ローカルの Chromium と同様に、
実行がリースを保持している間は、あなたのマシン上のどのプログラムもそのトンネルを使えます。

## 制限事項

- **Android のみ。** E2B には iOS のサンドボックスがないため、`e2b()` は iOS ターゲットを拒否します。
- **Android のイメージ。** E2B 上の Android 16 は x86_64 のみで、Google Play Services がなく、
  ソフトウェアでレンダリングされます。ネイティブライブラリを含むアプリには x86_64 のビルドが必要です。
  [E2B の Android のページ](https://e2b.dev/docs/use-cases/android) を参照してください。
  プロバイダーがインストールするのは `.apk` で、`.aab` ではありません。
- **課金。** サンドボックスは実行中に課金されます。Android のサンドボックスと worker スコープの
  ブラウザサンドボックスは、テストが使っていない間も実行の開始から終了まで動作します。
  attempt スコープのブラウザサンドボックスは、その試行の間だけ動作します。
- **停止した実行。** ランナーがサンドボックスを削除する前に強制終了された場合、
  E2B は `timeoutMs` の終了時にサンドボックスを削除します。
