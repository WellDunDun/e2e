[Moli](https://github.com/lexmount/moli) は、Chrome DevTools Protocol を話す
オープンソースのブラウザです。`@e2e-dev/moli` の `moli()` は、ワーカースロットごとに 1 つの
ローカルブラウザを起動し、実行の終了とともに停止します。

## Moli のターゲットを開始する

[Moli のバイナリ](https://github.com/lexmount/moli#direct-installation)
と、次のパッケージをインストールします。

<CodeGroup>
```bash npm
npm install --save-dev e2e @e2e-dev/web @e2e-dev/moli
```

```bash pnpm
pnpm add -D e2e @e2e-dev/web @e2e-dev/moli
```

```bash bun
bun add -d e2e @e2e-dev/web @e2e-dev/moli
```
</CodeGroup>

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { moli } from '@e2e-dev/moli';

export default {
  targets: [
    {
      name: 'moli',
      engine: web({ browser: moli() }),
      app: { url: 'http://localhost:3000' },
    },
  ],
} satisfies E2EConfig;
```

[`e2e run`](/reference/cli#e2e-run) でテストを実行します。各ワーカーは、空いている
ループバックポート上の個別の Moli プロセスを使います。10 秒以内に CDP を公開しない
サーバーは、そのリースが失敗します。

## ブラウザを設定する

| オプション | デフォルト | 意味 |
| --- | --- | --- |
| `binary` | `MOLI_PATH`、次に `PATH`、次に `~/.local/bin/moli` | 実行ファイルのパスまたは名前。ブラウザの起動時に、実行の環境から解決されます。 |
| `layout` | `true` | オンデマンドのレイアウトとスクリーンショットのために `--layout` を渡します。 |
| `loadResources` | `true` | 任意の画像、フォント、音声、動画、メディア、テキストトラックを取得するために `--resource` を渡します。 |
| `args` | `[]` | 追加の `moli serve` フラグ。 |

このプロバイダーはワーカースコープに対応しています。試行ごとのリースは実装されていません。

<Accordion title="自分で起動したサーバーに接続する">
別のターミナルで Moli を起動します。

```bash
moli serve --host 127.0.0.1 --port 19222 --layout --resource
```

接続には Web エンジンの `connect` オプションを使います。実行が終わってもこのサーバーは動作したままです。

```ts
web({ connect: { cdpEndpoint: () => process.env.MOLI_CDP_URL?.trim() || 'http://127.0.0.1:19222' } })
```
</Accordion>

## ブラウザの互換性を確認する

デプロイする Moli のビルドに対してテストスイートを実行してください。CDP の互換性の不足については
[アップストリームの issue](https://github.com/lexmount/moli/issues) を確認してください。
