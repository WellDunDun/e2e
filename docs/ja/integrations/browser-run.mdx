`@e2e-dev/browser-run` の `browserRun()` は、各ワーカースロット、または各テストの試行に、Cloudflare がホストする Chromium ブラウザを割り当てます。
テストは同じ Web エンジンとフィクスチャを使います。

## アカウントを接続する

アカウントに対する `Browser Rendering - Edit` 権限を持つ [Cloudflare API トークン](https://developers.cloudflare.com/browser-run/cdp/) を作成します。
`e2e run` を開始する環境で、`CLOUDFLARE_ACCOUNT_ID` と `CLOUDFLARE_API_TOKEN` を設定します。

`e2e` と `@e2e-dev/web` に加えて、プロバイダーをインストールします。

<CodeGroup>
```bash npm
npm install --save-dev @e2e-dev/browser-run
```

```bash pnpm
pnpm add -D @e2e-dev/browser-run
```

```bash bun
bun add -d @e2e-dev/browser-run
```
</CodeGroup>

ターゲットのブラウザを設定します。

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';
import { browserRun } from '@e2e-dev/browser-run';

export default {
  targets: [{
    name: 'cloudflare',
    engine: web({ browser: browserRun() }),
    app: { url: 'https://staging.example.com' },
  }],
  workers: 2,
} satisfies E2EConfig;
```

公開されている HTTPS のアプリ URL を使ってください。ホスト型ブラウザはランナーの `localhost` に到達できません。ローカルのアプリはトンネル経由で公開してください。

## ブラウザの存続期間を設定する

| オプション | デフォルト | 意味 |
| --- | --- | --- |
| `scope` | `'worker'` | ワーカースロットごとに 1 つのブラウザ。`'attempt'` は、試行とリトライのたびに新しいブラウザを借ります。 |
| `keepAlive` | `600000` | 非アクティブ時のタイムアウト（ミリ秒）。`10000` から `1200000` まで。 |

タイムアウトは、接続中であっても、CDP コマンドのない時間を数えます。テストが 10 分より長く停止する可能性がある場合は、`keepAlive` を増やしてください。

ワーカースコープでは、試行ごとに分離されたコンテキストが作成されます。
試行スコープでは、新しいブラウザのデフォルトコンテキストを使い、トランスポートが切断された後にそのブラウザへ再接続できます。
[試行ごとのプロバイダーの制限](/browser#hosted-browsers) が適用されます。

セッションはティアダウン時に削除されます。クリーンアップの前にランナーが終了した場合は、非アクティブ時のタイムアウトによってブラウザが終了します。

## 互換性を確認する

Chromium、ナビゲーション、ロケーター、ネットワークルート、Cookie、スクリーンショット、Web エンジンのスクリーンキャスト動画は CDP を使います。
CDP の認可ヘッダーはブラウザとの接続を認証するもので、ページのリクエストヘッダーにはなりません。

Browser Run では、`browser.back()` や `browser.forward()` の後にページの `load` イベントを待つ間に、履歴のナビゲーションがタイムアウトすることがあります。

リモートでのファイルのダウンロードには対応していません。Browser Run は、プロバイダーが読み取れるブラウザのファイルシステム API を公開していません。
Cloudflare ネイティブのセッション録画はレポートに添付されません。
[動画](/reference/config#video) が有効な場合、Web エンジンは試行ごとに WebM のスクリーンキャストを録画します。

`workers` は、アカウントの [同時実行数と取得の制限](https://developers.cloudflare.com/browser-run/limits/) の範囲内に収めてください。
HTTP の `401` または `403` は、確認すべきトークンの権限を示します。
