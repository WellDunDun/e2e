公式インテグレーションは、エンジンのプロバイダーインターフェースを通じて、ホスト型サービスから
ターゲットに `browser` または `device` を提供する 1 つのパッケージです。
設定で変わるのは、ターゲットの `browser` または `device` だけです。

## インテグレーションのないサービスを使う

その他のサービスについては、プロジェクト内に小さなプロバイダーを書きます。Web エンジンには
[`BrowserProvider`](/browser#hosted-browsers)、モバイルエンジンには
[`DeviceProvider`](/mobile#hosted-devices) を書きます。

GitHub Actions、Expo Workflows、Norrix などの CI サービスで e2e を実行するには、
[継続的インテグレーション](/ci) を参照してください。
