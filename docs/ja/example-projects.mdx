各サンプルは単体で動くあいさつアプリで、3 つのロケーターテストと 2 つの
エージェントテストがあります。エージェントテストの 1 つは名前に対するあいさつを取得し、もう 1 つは
名前が空のときのエラーをチェックします。各サンプルは、公開済みの e2e パッケージを npm からインストールします。

## サンプルを実行する

プロジェクトの README に従って、インストール、ビルド、実行を行います。設定と
テストはアプリの隣に置かれています。ネイティブ、Flutter、.NET MAUI のプロジェクトでは
`e2e/` フォルダーにあります。

ロケーターテストにはモデルは必要ありません。エージェントテストは Vercel AI Gateway を使い、
`AI_GATEWAY_API_KEY` が設定されていない場合はスキップされます。
